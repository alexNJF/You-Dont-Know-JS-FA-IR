# SIMD

در کتاب *Async & Performance* این مجموعه، Single Instruction, Multiple Data (SIMD) را مفصل‌تر پوشش داده‌ایم، اما این‌جا هم ارزش یک اشاره‌ی کوتاه دارد چون یکی از گزینه‌های محتمل برای ورود به آینده‌ی JS بود.

API مربوط به SIMD چند دستور low-level (در سطح CPU) را در اختیار می‌گذارد که می‌توانند هم‌زمان روی بیش از یک مقدار عددی عمل کنند. مثلاً می‌توانید دو *vector* شامل ۴ یا ۸ عدد تعریف کنید و عناصر متناظرشان را یک‌باره ضرب کنید (data parallelism).

مثال:

```js
var v1 = SIMD.float32x4( 3.14159, 21.0, 32.3, 55.55 );
var v2 = SIMD.float32x4( 2.1, 3.2, 4.3, 5.4 );

SIMD.float32x4.mul( v1, v2 );
// [ 6.597339, 67.2, 138.89, 299.97 ]
```

SIMD علاوه بر `mul(..)` (ضرب)، عملیات دیگری مثل `sub()`، `div()`، `abs()`، `neg()`، `sqrt()` و موارد بیشتر را هم شامل می‌شود.

عملیات ریاضی موازی برای نسل بعدی برنامه‌های JS با کارایی بالا حیاتی است.
