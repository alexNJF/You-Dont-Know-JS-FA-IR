# پراپرتی‌های آبجکت و `...`

همان‌طور که در بخش «Too Many, Too Few, Just Enough» فصل ۲ دیدیم، عملگر `...` برای spread یا gather کردن آرایه‌ها کاملاً واضح است. اما برای آبجکت‌ها چطور؟

این قابلیت برای ES6 بررسی شد، ولی به بعد از ES6 (یعنی «ES7»، «ES2016» یا ...) موکول شد. این‌طور ممکن است کار کند:

```js
var o1 = { a: 1, b: 2 },
	o2 = { c: 3 },
	o3 = { ...o1, ...o2, d: 4 };

console.log( o3.a, o3.b, o3.c, o3.d );
// 1 2 3 4
```

عملگر `...` احتمالاً برای gather کردن دوباره‌ی پراپرتی‌های destructure شده‌ی آبجکت داخل یک آبجکت جدید هم استفاده می‌شود:

```js
var o1 = { b: 2, c: 3, d: 4 };
var { b, ...o2 } = o1;

console.log( b, o2.c, o2.d );		// 2 3 4
```

اینجا `...o2` پراپرتی‌های destructure شده‌ی `c` و `d` را دوباره داخل آبجکت `o2` جمع می‌کند (`o2` برخلاف `o1` پراپرتی `b` ندارد).

دوباره تاکید: این‌ها در حد proposalهای پس از ES6 بودند. اما اگر نهایی شوند، قابلیت جذابی خواهند بود.
