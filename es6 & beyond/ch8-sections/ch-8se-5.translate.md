# `Array#includes(..)`

یکی از کارهای بسیار رایج توسعه‌دهنده‌های JS، جست‌وجوی یک مقدار داخل آرایه است. روش کلاسیک همیشه این بوده:

```js
var vals = [ "foo", "bar", 42, "baz" ];

if (vals.indexOf( 42 ) >= 0) {
	// found it!
}
```

دلیل چک `>= 0` این است که `indexOf(..)` اگر پیدا کند عدد `0` یا بیشتر برمی‌گرداند، و اگر پیدا نکند `-1`. یعنی داریم از تابعی که «اندیس» برمی‌گرداند در context بولی استفاده می‌کنیم. چون `-1` truthy است (نه falsy)، باید چک دستی انجام دهیم.

در کتاب *Types & Grammar* این مجموعه، الگوی دیگری را بررسی کردم که کمی بیشتر می‌پسندم:

```js
var vals = [ "foo", "bar", 42, "baz" ];

if (~vals.indexOf( 42 )) {
	// found it!
}
```

عملگر `~` خروجی `indexOf(..)` را به بازه‌ای تبدیل می‌کند که برای coercion بولی مناسب‌تر است: `-1` به `0` (falsy) تبدیل می‌شود و هر چیز دیگر مقدار non-zero (truthy) می‌دهد.

به نظرم این بهتر است، اما خیلی‌ها مخالف‌اند. با این حال کسی نمی‌تواند بگوید منطق جست‌وجوی `indexOf(..)` کامل است؛ مثلاً مقدار `NaN` را پیدا نمی‌کند.

برای همین پیشنهادی با حمایت زیاد مطرح شد تا متد جست‌وجوی واقعیِ بولی به آرایه اضافه شود، به نام `includes(..)`:

```js
var vals = [ "foo", "bar", 42, "baz" ];

if (vals.includes( 42 )) {
	// found it!
}
```

**نکته:** `Array#includes(..)` از منطق matchی استفاده می‌کند که `NaN` را پیدا می‌کند، اما بین `-0` و `0` تفاوت نمی‌گذارد (کتاب *Types & Grammar* را ببینید). اگر در برنامه‌تان `-0` مهم نیست، احتمالاً دقیقاً همین را می‌خواهید. اگر *مهم* است، باید منطق جست‌وجوی خودتان را بنویسید؛ احتمالاً با `Object.is(..)` (فصل ۶).
