# مرور

ES6 (هرچند بعضی‌ها ممکن است آن را ES2015 بنامند) در زمان نگارش این متن تازه در حال عرضه است و چیزهای جدید زیادی دارد که باید یاد بگیرید!

اما مهم‌تر از آن، باید طرز فکرتان را با شیوهٔ جدید تکامل JavaScript هماهنگ کنید. دیگر مثل گذشته نیست که سال‌ها منتظر بمانیم تا یک سند رسمی رأی تأیید بگیرد.

اکنون قابلیت‌های JavaScript هر زمان آماده شوند وارد مرورگرها می‌شوند، و این به شما بستگی دارد که زود سوار این قطار شوید یا چند سال بعد مجبور به جبرانِ پرهزینه باشید.

JavaScript آینده هر برچسبی هم که بگیرد، بسیار سریع‌تر از قبل حرکت خواهد کرد. transpilerها و shims/polyfills ابزارهای مهمی هستند تا شما را در خط مقدم مسیری که زبان به سمت آن می‌رود نگه دارند.

اگر بخواهیم یک پیام کلیدی از واقعیت جدید JavaScript بگیریم، این است که از همهٔ توسعه‌دهندگان JS با جدیت خواسته می‌شود از لبهٔ عقب منحنی به لبهٔ جلو بیایند. و یادگیری ES6 نقطهٔ شروع این مسیر است!
