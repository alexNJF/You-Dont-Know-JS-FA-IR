# Setها

Set مجموعه‌ای از مقدارهای یکتا است (مقدار تکراری نادیده گرفته می‌شود).

API مربوط به set شبیه map است. متد `add(..)` جای `set(..)` را می‌گیرد (کمی طنزآمیز!) و متد `get(..)` هم وجود ندارد.

مثال:

```js
var s = new Set();

var x = { id: 1 },
	y = { id: 2 };

s.add( x );
s.add( y );
s.add( x );

s.size;							// 2

s.delete( y );
s.size;							// 1

s.clear();
s.size;							// 0
```

فرم سازنده‌ی `Set(..)` شبیه `Map(..)` است، از این نظر که iterable می‌گیرد، مثل یک set دیگر یا حتی یک آرایه‌ی ساده از مقدارها. اما برخلاف `Map(..)` که فهرست *entries* (آرایه‌ای از آرایه‌های کلید/مقدار) می‌خواهد، `Set(..)` فهرست *values* (آرایه‌ی مقدارها) می‌خواهد:

```js
var x = { id: 1 },
	y = { id: 2 };

var s = new Set( [x,y] );
```

set نیازی به `get(..)` ندارد چون شما از set مقدار «برنمی‌دارید»، بلکه بررسی می‌کنید مقدار هست یا نه، با `has(..)`:

```js
var s = new Set();

var x = { id: 1 },
	y = { id: 2 };

s.add( x );

s.has( x );						// true
s.has( y );						// false
```

**نکته:** الگوریتم مقایسه در `has(..)` تقریباً با `Object.is(..)` (فصل ۶) یکسان است، با این تفاوت که `-0` و `0` را یکسان در نظر می‌گیرد، نه متمایز.

### Iteratorهای Set

Setها همان متدهای iterator مربوط به map را دارند. رفتارشان برای set متفاوت است، اما نسبت به iteratorهای map حالت متقارن دارد. مثال:

```js
var s = new Set();

var x = { id: 1 },
	y = { id: 2 };

s.add( x ).add( y );

var keys = [ ...s.keys() ],
	vals = [ ...s.values() ],
	entries = [ ...s.entries() ];

keys[0] === x;
keys[1] === y;

vals[0] === x;
vals[1] === y;

entries[0][0] === x;
entries[0][1] === x;
entries[1][0] === y;
entries[1][1] === y;
```

iteratorهای `keys()` و `values()` هر دو فهرست مقدارهای یکتای set را تولید می‌کنند. iterator `entries()` فهرستی از آرایه‌های entry می‌دهد که هر دو آیتم هر آرایه، همان مقدار یکتای set هستند. iterator پیش‌فرض set همان `values()` است.

ویژگی یکتابودن set مهم‌ترین مزیت آن است. مثال:

```js
var s = new Set( [1,2,3,4,"1",2,4,"5"] ),
	uniques = [ ...s ];

uniques;						// [1,2,3,4,"1","5"]
```

یکتایی در set coercion انجام نمی‌دهد، پس `1` و `"1"` دو مقدار متفاوت در نظر گرفته می‌شوند.
