# Number Literal Extensions

قبل از ES5، number literalها شبیه این بودند -- فرم octal به‌صورت رسمی در استاندارد نیامده بود و فقط به‌عنوان extension پذیرفته‌شدهٔ مرورگرها وجود داشت:

```js
var dec = 42,
	oct = 052,
	hex = 0x2a;
```

**نکته:** هرچند عدد را در مبناهای مختلف می‌نویسید، آنچه ذخیره می‌شود value ریاضی عدد است و تفسیر خروجی پیش‌فرض همیشه مبنای 10 است. هر سه متغیر در snippet بالا value برابر `42` دارند.

برای روشن‌تر شدن اینکه `052` یک extension غیر استاندارد بوده، مثال زیر را ببینید:

```js
Number( "42" );				// 42
Number( "052" );			// 52
Number( "0x2a" );			// 42
```

ES5 همچنان فرم octal توسعه‌داده‌شدهٔ مرورگرها را (با همین ناسازگاری‌ها) مجاز نگه داشت، با این تفاوت که در strict mode فرم octal literal (`052`) غیرمجاز شد. این محدودیت عمدتاً به این دلیل بود که بسیاری از توسعه‌دهندگان (با عادت از زبان‌های دیگر) برای تراز کردن کد، بی‌ضرر به نظر می‌رسید که اول عددهای ده‌دهی `0` بگذارند، و ناخواسته value عدد را کاملاً عوض می‌کردند!

ES6 مسیر تغییر در نمایش number literalهای غیر ده‌دهی را ادامه می‌دهد. حالا یک فرم octal رسمی داریم، فرم hexadecimal اصلاح‌شده داریم، و فرم binary کاملاً جدید داریم. به دلایل سازگاری وب، فرم قدیمی octal یعنی `052` در non-strict mode همچنان قانونی می‌ماند (هرچند مشخص‌نشده)، اما عملاً دیگر نباید استفاده شود.

فرم‌های جدید number literal در ES6:

```js
var dec = 42,
	oct = 0o52,			// or `0O52` :(
	hex = 0x2a,			// or `0X2a` :/
	bin = 0b101010;		// or `0B101010` :/
```

تنها فرم ده‌دهی مجاز، مبنای 10 است. octal و hexadecimal و binary همگی فرم عدد صحیح هستند.

و نمایش رشته‌ای این فرم‌ها هم قابل coercion/تبدیل به معادل عددی خودشان هستند:

```js
Number( "42" );			// 42
Number( "0o52" );		// 42
Number( "0x2a" );		// 42
Number( "0b101010" );	// 42
```

هرچند دقیقاً قابلیت جدید ES6 نیست، ولی واقعیتی کمتر شناخته‌شده این است که می‌توان مسیر تبدیل را برعکس هم رفت (تقریباً):

```js
var a = 42;

a.toString();			// "42" -- also `a.toString( 10 )`
a.toString( 8 );		// "52"
a.toString( 16 );		// "2a"
a.toString( 2 );		// "101010"
```

در واقع می‌توانید عدد را این‌گونه در هر مبنایی از `2` تا `36` نمایش دهید، هرچند خارج از مبناهای رایج 2، 8، 10 و 16 به‌ندرت کاربرد دارد.
