# مرور

ES6 حجم زیادی syntax جدید به JavaScript اضافه می‌کند، بنابراین چیزهای زیادی برای یادگیری داریم!

بیشتر این قابلیت‌ها برای کم‌کردن دردسر الگوهای رایج برنامه‌نویسی طراحی شده‌اند؛ مثل تعیین default value برای parameterهای تابع و جمع‌کردن «بقیهٔ» parameterها در یک array. Destructuring ابزار قدرتمندی است برای بیان فشرده‌تر assignment از valueهای arrayها و objectهای تودرتو.

هرچند قابلیت‌هایی مثل arrow functionهای `=>` ممکن است ظاهراً فقط برای syntax کوتاه‌تر و خوش‌ظاهرتر باشند، در واقع رفتارهای مشخصی دارند که باید فقط در موقعیت‌های مناسب، آگاهانه از آن‌ها استفاده کنید.

پشتیبانی گسترده‌تر از Unicode، ترفندهای جدید برای regular expressionها، و حتی primitive type جدیدی به نام `symbol` هم تکامل نحوی ES6 را کامل می‌کنند.
