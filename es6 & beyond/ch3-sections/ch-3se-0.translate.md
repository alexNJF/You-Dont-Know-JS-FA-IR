# شما جاوااسکریپت را نمی‌دانید: ES6 و فراتر
# فصل ۳: سازمان‌دهی

نوشتن کد JS یک موضوع است، اما سازمان‌دهی درست آن موضوع دیگری است. استفاده از الگوهای رایج برای سازمان‌دهی و استفادهٔ مجدد، تأثیر زیادی در بهتر شدن خوانایی و قابل‌فهم بودن کد دارد. یادتان باشد: کد به همان اندازه که برای دادن دستور به کامپیوتر است، برای برقراری ارتباط با توسعه‌دهندگان دیگر هم هست.

ES6 چند قابلیت مهم دارد که این الگوها را به‌صورت محسوسی بهتر می‌کند؛ از جمله: iteratorها، generatorها، moduleها و classها.
