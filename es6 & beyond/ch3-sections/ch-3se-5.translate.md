# مرور

ES6 چند قابلیت جدید مهم برای سازمان‌دهی کد معرفی می‌کند:

* Iteratorها دسترسی ترتیبی به داده یا عملیات می‌دهند و با قابلیت‌هایی مثل `for..of` و `...` مصرف می‌شوند.
* Generatorها functionهایی هستند که می‌توانند محلی pause/resume شوند و با iterator کنترل می‌شوند. از طریق پیام‌رسانی `yield`/`next(..)` می‌توانند value تولید کنند.
* Moduleها encapsulation خصوصی + API عمومی export‌شده می‌دهند. تعریفشان file-based است، singleton هستند، و در زمان compile به‌صورت static resolve می‌شوند.
* Classها syntax تمیزتری روی کدنویسی prototype-based فراهم می‌کنند. `super` هم برخی مسائل سخت ارجاع نسبی در زنجیرهٔ `[[Prototype]]` را حل می‌کند.

این ابزارهای جدید باید اولین گزینهٔ شما برای بهبود معماری پروژه‌های JS با رویکرد ES6 باشند.
