# متا پراپرتی‌ها

در بخش "`new.target`" از فصل ۳، مفهومی جدید در ES6 معرفی کردیم: meta property. همان‌طور که از اسمش پیداست، meta property قرار است اطلاعات متای ویژه‌ای را در قالب دسترسی پراپرتی فراهم کند؛ چیزی که در حالت عادی ممکن نبود.

در مورد `new.target`، کلیدواژه‌ی `new` نقش context برای دسترسی پراپرتی را دارد. واضح است که خود `new` یک آبجکت نیست، و همین این قابلیت را ویژه می‌کند. با این حال وقتی `new.target` داخل یک constructor call استفاده شود (تابع/متدی که با `new` فراخوانی شده)، `new` به یک context مجازی تبدیل می‌شود تا `new.target` بتواند به constructor هدفی اشاره کند که `new` آن را فراخوانی کرده.

این یک نمونه‌ی روشن از عملیات متاپروگرمینگ است؛ چون هدف این است که از داخل constructor call بفهمیم target اصلی `new` چه بوده، معمولاً برای introspection (بررسی نوع/ساختار) یا دسترسی به پراپرتی‌های ایستا.

مثلاً ممکن است بخواهید رفتار constructor بر اساس این‌که مستقیم صدا زده شده یا از طریق کلاس فرزند، متفاوت باشد:

```js
class Parent {
	constructor() {
		if (new.target === Parent) {
			console.log( "Parent instantiated" );
		}
		else {
			console.log( "A child instantiated" );
		}
	}
}

class Child extends Parent {}

var a = new Parent();
// Parent instantiated

var b = new Child();
// A child instantiated
```

اینجا یک ظرافت کوچک وجود دارد: `constructor()` داخل تعریف کلاس `Parent` در واقع نام lexical کلاس (`Parent`) را می‌گیرد، هرچند از روی سینتکس انگار کلاس موجودیتی جدا از constructor است.

**هشدار:** مثل همه‌ی تکنیک‌های متاپروگرمینگ، مواظب باشید کد آن‌قدر «باهوش‌بازی» درنیاورد که خودِ آینده‌تان یا دیگر نگه‌دارنده‌های کد نتوانند بفهمندش. این ترفندها را با احتیاط استفاده کنید.
