# مرور

ES6 helperهای API زیادی به آبجکت‌های native داخلی اضافه می‌کند:

* `Array` توابع ایستای `of(..)` و `from(..)` را اضافه می‌کند، و همچنین توابع prototype مثل `copyWithin(..)` و `fill(..)`.
* `Object` توابع ایستایی مثل `is(..)` و `assign(..)` اضافه می‌کند.
* `Math` توابع ایستایی مثل `acosh(..)` و `clz32(..)` اضافه می‌کند.
* `Number` ویژگی‌های ایستایی مثل `Number.EPSILON` و همچنین توابع ایستایی مثل `Number.isFinite(..)` اضافه می‌کند.
* `String` توابع ایستایی مثل `String.fromCodePoint(..)` و `String.raw(..)` اضافه می‌کند، و همچنین توابع prototype مثل `repeat(..)` و `includes(..)`.

بیشتر این اضافه‌شدن‌ها قابل polyfill هستند (مثل ES6 Shim) و الهام‌گرفته از utilityهایی هستند که در کتابخانه‌ها/فریم‌ورک‌های رایج JS از قبل وجود داشتند.
