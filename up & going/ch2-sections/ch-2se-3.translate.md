# شرط‌ها

علاوه بر دستور `if` که به‌طور خلاصه در فصل ۱ معرفی کردیم، جاوااسکریپت چند مکانیزم شرطی دیگر ارائه می‌دهد که باید به آن‌ها نگاهی بیندازیم.

گاهی ممکن است خود را در حال نوشتن یک سری دستورات `if..else..if` مانند این ببینید:

```js
if (a == 2) {
	// do something
}
else if (a == 10) {
	// do another thing
}
else if (a == 42) {
	// do yet another thing
}
else {
	// fallback to here
}
```

این ساختار کار می‌کند، اما کمی طولانی است چون باید آزمون `a` را برای هر مورد مشخص کنید. گزینهٔ دیگری وجود دارد، دستور `switch`:

```js
switch (a) {
	case 2:
		// do something
		break;
	case 10:
		// do another thing
		break;
	case 42:
		// do yet another thing
		break;
	default:
		// fallback to here
}
```

`break` مهم است اگر می‌خواهید فقط دستور(های) یک `case` اجرا شود. اگر `break` را از یک `case` حذف کنید، و آن `case` مطابقت کند یا اجرا شود، اجرا با دستورات `case` بعدی ادامه می‌یابد صرف‌نظر از مطابقت آن `case`. این به‌اصطلاح «fall through» گاهی مفید/مطلوب است:

```js
switch (a) {
	case 2:
	case 10:
		// some cool stuff
		break;
	case 42:
		// other stuff
		break;
	default:
		// fallback
}
```

اینجا، اگر `a` یا `2` یا `10` باشد، دستورات کد «some cool stuff» را اجرا می‌کند.

شکل دیگر شرط در جاوااسکریپت «عملگر شرطی» است که اغلب «عملگر سه‌تایی» نامیده می‌شود. مانند شکل مختصرتر یک دستور تکی `if..else` است، مانند:

```js
var a = 42;

var b = (a > 41) ? "hello" : "world";

// similar to:

// if (a > 41) {
//    b = "hello";
// }
// else {
//    b = "world";
// }
```

اگر عبارت آزمون (`a > 41` اینجا) به‌عنوان `true` ارزیابی شود، بند اول (`"hello"`) نتیجه می‌دهد، در غیر این صورت بند دوم (`"world"`) نتیجه می‌دهد، و هر چه نتیجه باشد به `b` اختصاص می‌یابد.

عملگر شرطی لازم نیست در یک انتساب استفاده شود، اما قطعاً رایج‌ترین کاربرد آن است.

**Note:** برای اطلاعات بیشتر دربارهٔ آزمون شرایط و الگوهای دیگر برای `switch` و `? :`، به عنوان *Types & Grammar* این مجموعه مراجعه کنید.
