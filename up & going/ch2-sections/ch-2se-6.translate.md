# شناسهٔ `this`

مفهوم دیگر بسیار رایج که در جاوااسکریپت به‌اشتباه درک می‌شود، شناسهٔ `this` است. باز هم، چند فصل دربارهٔ آن در عنوان *this & Object Prototypes* این مجموعه وجود دارد، بنابراین اینجا فقط به‌طور خلاصه مفهوم را معرفی می‌کنیم.

اگرچه ممکن است اغلب به نظر برسد که `this` به «الگوهای شیءگرا» مربوط است، در JS مکانیزمی متفاوت است.

اگر یک function reference به `this` در داخل خود داشته باشد، آن reference به `this` معمولاً به یک `object` اشاره می‌کند. اما به کدام `object` اشاره می‌کند بستگی به نحوهٔ فراخوانی function دارد.

مهم است درک کنید که `this` *به خود function اشاره نمی‌کند*، که رایج‌ترین تصور اشتباه است.

در اینجا یک تصویرسازی سریع آمده است:

```js
function foo() {
	console.log( this.bar );
}

var bar = "global";

var obj1 = {
	bar: "obj1",
	foo: foo
};

var obj2 = {
	bar: "obj2"
};

// --------

foo();				// "global"
obj1.foo();			// "obj1"
foo.call( obj2 );		// "obj2"
new foo();			// undefined
```

چهار قانون برای نحوهٔ تنظیم شدن `this` وجود دارد، و آن‌ها در آن چهار خط آخر قطعه کد نشان داده شده‌اند.

1. `foo()` در حالت غیر strict mode `this` را به object سراسری تنظیم می‌کند — در strict mode، `this` مقدار `undefined` می‌شد و در دسترسی به ویژگی `bar` خطا می‌گرفتید — بنابراین `"global"` مقداری است که برای `this.bar` یافت می‌شود.
2. `obj1.foo()` `this` را به object `obj1` تنظیم می‌کند.
3. `foo.call(obj2)` `this` را به object `obj2` تنظیم می‌کند.
4. `new foo()` `this` را به یک object خالی کاملاً جدید تنظیم می‌کند.

نتیجه: برای درک اینکه `this` به چه چیزی اشاره می‌کند، باید نحوهٔ فراخوانی function مورد نظر را بررسی کنید. یکی از آن چهار روشی خواهد بود که نشان داده شد، و آن پاسخ می‌دهد که `this` چیست.

**Note:** برای اطلاعات بیشتر دربارهٔ `this`، به فصل‌های ۱ و ۲ عنوان *this & Object Prototypes* این مجموعه مراجعه کنید.
