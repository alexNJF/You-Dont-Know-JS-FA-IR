# Scope و Closures

شاید یکی از بنیادی‌ترین چیزهایی که باید به‌سرعت با آن کنار بیایید نحوهٔ واقعی کار scoping متغیرها در JavaScript است. داشتن *باورهای* مبهم و حکایتی دربارهٔ scope کافی نیست.

عنوان *Scope & Closures* با رد این تصور رایج شروع می‌کند که JS «زبان interpreted» است و بنابراین compile نمی‌شود. نه.

موتور JS کدتان را دقیقاً قبل از (و گاهی حین!) اجرا compile می‌کند. پس از درک عمیق‌تر رویکرد compiler به کدمان برای فهم نحوهٔ پیدا کردن و برخورد با اعلام متغیر و تابع استفاده می‌کنیم. در مسیر، استعارهٔ معمول برای مدیریت scope متغیر JS، «Hoisting»، را می‌بینیم.

این درک حیاتی از «lexical scope» پایهٔ کاوش closure در فصل آخر کتاب است. Closure شاید مهم‌ترین مفهوم در کل JS باشد، اما اگر ابتدا نحوهٔ کار scope را محکم درک نکرده باشید، closure احتمالاً فراتر از درک شما می‌ماند.

یک کاربرد مهم closure الگوی module است، همان‌طور که در فصل ۲ این کتاب به‌طور خلاصه معرفی کردیم. الگوی module شاید رایج‌ترین الگوی سازماندهی کد در کل JavaScript است؛ درک عمیق آن باید یکی از بالاترین اولویت‌هایتان باشد.
