# ES6 و فراتر

صرف‌نظر از اینکه چقدر فکر می‌کنید تا اینجا JavaScript را تسلط یافته‌اید، حقیقت این است که JavaScript هرگز از تکامل بازنمی‌ایستد، و علاوه بر این، نرخ تکامل به‌سرعت در حال افزایش است. این واقعیت تقریباً استعاره‌ای از روح این مجموعه است، که بپذیریم هرگز کاملاً *نمی‌دانیم* هر بخش JS را، چون به محض تسلط بر همه، چیزهای جدیدی در راه است که باید یاد بگیرید.

این عنوان به هر دو دید کوتاه‌مدت و میان‌مدت جهت زبان اختصاص دارد، نه فقط چیزهای *شناخته‌شده* مثل ES6 بلکه چیزهای *محتمل* فراتر.

در حالی که همهٔ عناوین این مجموعه وضعیت JavaScript در زمان نوشتن را در بر می‌گیرند، که میانهٔ پذیرش ES6 است، تمرکز اصلی مجموعه بیشتر بر ES5 بوده است. حالا می‌خواهیم توجهمان را به ES6، ES7 و ... معطوف کنیم.

از آنجا که ES6 در زمان نوشتن تقریباً کامل است، *ES6 & Beyond* با تقسیم چیزهای مشخص از منظرهٔ ES6 به چند دستهٔ کلیدی شروع می‌کند، از جمله سینتکس جدید، ساختارهای دادهٔ جدید (collections)، و قابلیت‌ها و APIهای پردازش جدید. هر یک از این ویژگی‌های جدید ES6 را با سطوح مختلف جزئیات پوشش می‌دهیم، از جمله مرور جزئیاتی که در کتاب‌های دیگر این مجموعه مطرح شده‌اند.

چیزهای هیجان‌انگیز ES6 برای خواندن: destructuring، مقادیر پیش‌فرض پارامتر، symbolها، متدهای مختصر، computed properties، arrow functionها، block scoping، promiseها، generatorها، iteratorها، moduleها، proxyها، weakmapها، و خیلی خیلی بیشتر! ES6 واقعاً پرمحتواست!

بخش اول کتاب نقشهٔ راهی برای همهٔ چیزهایی است که باید یاد بگیرید تا برای JavaScript جدید و بهبودیافته‌ای که در چند سال آینده می‌نویسید و کاوش می‌کنید آماده شوید.

بخش آخر کتاب توجه را به نگاهی کوتاه به چیزهایی معطوف می‌کند که احتمالاً در آیندهٔ نزدیک JavaScript انتظار داریم ببینیم. مهم‌ترین درک اینجاست که بعد از ES6، JS احتمالاً feature به feature تکامل می‌یابد نه version به version، یعنی می‌توانیم انتظار داشته باشیم این چیزهای آیندهٔ نزدیک خیلی زودتر از آنچه تصور می‌کنید بیایند.

آیندهٔ JavaScript روشن است. وقتش نیست شروع به یادگیری کنیم!؟
