# شما جاوااسکریپت را نمی‌دانید: شروع و پیشرفت - ویرایش اول
# فصل ۳: در مجموعه YDKJS

این مجموعه دربارهٔ چیست؟ به‌سادگی، دربارهٔ جدی گرفتن یادگیری *همهٔ بخش‌های JavaScript* است، نه فقط زیرمجموعه‌ای از زبان که کسی «بخش‌های خوب» نامیده، و نه فقط حداقل آنچه برای انجام کارتان نیاز دارید.

توسعه‌دهندگان جدی در زبان‌های دیگر انتظار دارند تلاش برای یادگیری اکثر یا همهٔ زبان(های) اصلی‌شان بکنند، اما به نظر می‌رسد توسعه‌دهندگان JS از این نظر متمایزند که معمولاً چندان از زبان یاد نمی‌گیرند. این چیز خوبی نیست، و نباید اجازه دهیم به‌عنوان هنجار ادامه یابد.

مجموعه *شما جاوااسکریپت را نمی‌دانید* (*YDKJS*) در تضاد کامل با رویکردهای معمول یادگیری JS است، و تقریباً با هر کتاب JS دیگری که می‌خوانید متفاوت است. شما را به چالش می‌کشد از محدودهٔ راحتی‌تان فراتر بروید و سؤال‌های عمیق‌تر «چرا» را برای هر رفتاری که می‌بینید بپرسید. آمادهٔ آن چالش هستید؟

از این فصل پایانی برای خلاصهٔ کوتاه آنچه از بقیهٔ کتاب‌های مجموعه انتظار دارید، و نحوهٔ مؤثرترین ساخت بنیاد یادگیری JS بر پایهٔ *YDKJS* استفاده می‌کنم.
