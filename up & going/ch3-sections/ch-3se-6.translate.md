# مرور

مجموعهٔ *YDKJS* به این گزاره اختصاص دارد که همهٔ توسعه‌دهندگان JS می‌توانند و باید همهٔ بخش‌های این زبان عالی را یاد بگیرند. نظر هیچ کس، فرضیات هیچ framework، و مهلت هیچ پروژه نباید بهانهٔ عدم یادگیری و درک عمیق JavaScript باشد.

هر حوزهٔ تمرکز مهم در زبان را می‌گیریم و کتابی کوتاه اما بسیار فشرده برای کاوش کامل همهٔ بخش‌هایی که شاید فکر می‌کردید می‌دانید اما احتمالاً کاملاً نمی‌دانستید اختصاص می‌دهیم.

«شما جاوااسکریپت را نمی‌دانید» انتقاد یا توهین نیست. درکی است که همهٔ ما، از جمله خودم، باید با آن کنار بیاییم. یادگیری JavaScript هدف نهایی نیست بلکه فرایند است. ما هنوز JavaScript را نمی‌دانیم. اما خواهیم دانست!
