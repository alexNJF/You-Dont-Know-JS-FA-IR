# خودتان امتحان کنید

این فصل هر مفهوم برنامه‌نویسی را با قطعات کد ساده معرفی می‌کند، همه به JavaScript نوشته شده (بدیهی است!).

نمی‌توان به اندازهٔ کافی تأکید کرد: هنگام گذر از این فصل — و ممکن است لازم باشد چند بار آن را مرور کنید — باید هر یک از این مفاهیم را با تایپ کردن کد خودتان تمرین کنید. ساده‌ترین راه باز کردن کنسول ابزارهای توسعه‌دهنده در نزدیک‌ترین مرورگرتان است (Firefox، Chrome، IE و غیره).

**Tip:** معمولاً می‌توانید کنسول توسعه‌دهنده را با میانبر صفحه‌کلید یا از منو اجرا کنید. برای اطلاعات دقیق‌تر دربارهٔ اجرا و استفاده از کنسول در مرورگر مورد علاقه‌تان، «Mastering The Developer Tools Console» را ببینید (http://blog.teamtreehouse.com/mastering-developer-tools-console). برای تایپ چند خط در کنسول یک‌جا، از `<shift> + <enter>` برای رفتن به خط بعدی استفاده کنید. وقتی خود `<enter>` را بزنید، کنسول همهٔ آنچه تازه تایپ کرده‌اید را اجرا می‌کند.

بیایید با فرایند اجرای کد در کنسول آشنا شویم. اول، پیشنهاد می‌کنم یک تب خالی در مرورگرتان باز کنید. من ترجیح می‌دهم با تایپ `about:blank` در نوار آدرس این کار را بکنم. سپس مطمئن شوید کنسول توسعه‌دهنده باز است، همان‌طور که گفتیم.

حالا این کد را تایپ کنید و ببینید چطور اجرا می‌شود:

```js
a = 21;

b = a * 2;

console.log( b );
```

تایپ این کد در کنسول Chrome باید چیزی شبیه این تولید کند:

<img src="fig1.png" width="500">

ادامه دهید، امتحان کنید. بهترین راه یادگیری برنامه‌نویسی شروع به کدنویسی است!

### Output

در قطعه کد قبلی، از `console.log(..)` استفاده کردیم. به‌طور خلاصه، ببینیم آن خط کد چه می‌کند.

شاید حدس زده باشید، اما دقیقاً این‌طور متن را (که *output* به کاربر هم گفته می‌شود) در کنسول توسعه‌دهنده چاپ می‌کنیم. دو ویژگی آن statement هست که باید توضیح دهیم.

اول، بخش `log( b )` فراخوانی تابع نامیده می‌شود (ببینید «Functions»). آنچه اتفاق می‌افتد این است که متغیر `b` را به آن تابع می‌دهیم، که از آن می‌خواهد مقدار `b` را بگیرد و در کنسول چاپ کند.

دوم، بخش `console.` ارجاع به object است که تابع `log(..)` در آن قرار دارد. در فصل ۲ اشیاء و ویژگی‌هایشان را با جزئیات بیشتر پوشش می‌دهیم.

راه دیگر ایجاد output که می‌توانید ببینید اجرای statement `alert(..)` است. مثلاً:

```js
alert( b );
```

اگر آن را اجرا کنید، متوجه می‌شوید که به‌جای چاپ output در کنسول، یک پنجرهٔ popup «OK» با محتوای متغیر `b` نشان می‌دهد. با این حال، استفاده از `console.log(..)` به‌طور کلی یادگیری کدنویسی و اجرای برنامه‌هایتان در کنسول را آسان‌تر از `alert(..)` می‌کند، چون می‌توانید چند مقدار را یک‌جا output کنید بدون قطع رابط مرورگر.

در این کتاب، از `console.log(..)` برای output استفاده می‌کنیم.

### Input

وقتی دربارهٔ output صحبت می‌کنیم، شاید دربارهٔ *input* هم کنجکاو باشید (یعنی دریافت اطلاعات از کاربر).

رایج‌ترین راه این است که صفحهٔ HTML المان‌های فرم (مثل جعبهٔ متن) به کاربر نشان دهد که بتواند تایپ کند، و سپس از JS برای خواندن آن مقادیر در متغیرهای برنامه استفاده کند.

اما راه ساده‌تری برای گرفتن input برای اهداف یادگیری و نمایش ساده مثل آنچه در این کتاب انجام می‌دهید وجود دارد. از تابع `prompt(..)` استفاده کنید:

```js
age = prompt( "Please tell me your age:" );

console.log( age );
```

شاید حدس زده باشید، پیامی که به `prompt(..)` می‌دهید — در این مورد `"Please tell me your age:"` — در popup چاپ می‌شود.

برای ساده نگه داشتن هنگام یادگیری مفاهیم پایهٔ برنامه‌نویسی، مثال‌های این کتاب input نیاز ندارند. اما حالا که دیدید چطور از `prompt(..)` استفاده کنید، اگر می‌خواهید خودتان را به چالش بکشید می‌توانید در کاوش مثال‌ها از input استفاده کنید.
