# شما جاوااسکریپت را نمی‌دانید: شروع و پیشرفت - ویرایش اول
# فصل ۱: مقدمه برنامه‌نویسی

به مجموعه *شما جاوااسکریپت را نمی‌دانید* (*YDKJS*) خوش آمدید.

*شروع و پیشرفت* مقدمه‌ای است بر چند مفهوم پایهٔ برنامه‌نویسی — که البته به‌طور خاص به سمت JavaScript (که اغلب به اختصار JS نامیده می‌شود) گرایش داریم — و نحوهٔ رویکرد و درک بقیهٔ عناوین این مجموعه. به‌ویژه اگر تازه وارد برنامه‌نویسی و/یا JavaScript شده‌اید، این کتاب به‌طور خلاصه آنچه را که برای *آماده شدن و شروع* نیاز دارید بررسی می‌کند.

این کتاب با توضیح اصول پایهٔ برنامه‌نویسی در سطحی بسیار کلی شروع می‌کند. عمدتاً برای کسانی است که با تجربهٔ برنامه‌نویسی کم یا بدون تجربه، *YDKJS* را شروع می‌کنند و به دنبال این کتاب‌ها برای کمک به شروع مسیر درک برنامه‌نویسی از دریچهٔ JavaScript هستند.

فصل ۱ را باید به‌عنوان مروری سریع بر چیزهایی که می‌خواهید بیشتر یاد بگیرید و تمرین کنید تا *وارد برنامه‌نویسی شوید* در نظر بگیرید. منابع عالی دیگری هم برای مقدمهٔ برنامه‌نویسی وجود دارد که می‌توانند به شما کمک کنند بیشتر در این موضوعات غوطه‌ور شوید، و شما را تشویق می‌کنم علاوه بر این فصل از آن‌ها هم یاد بگیرید.

وقتی با مبانی کلی برنامه‌نویسی راحت شدید، فصل ۲ شما را به آشنایی با سبک برنامه‌نویسی JavaScript راهنمایی می‌کند. فصل ۲ معرفی می‌کند که JavaScript چیست، اما باز هم راهنمای جامعی نیست — بقیهٔ کتاب‌های *YDKJS* برای همین هستند!

اگر از قبل با JavaScript نسبتاً راحت هستید، ابتدا فصل ۳ را به‌عنوان نگاهی کوتاه به آنچه از *YDKJS* انتظار دارید ببینید، سپس مستقیم شروع کنید!
