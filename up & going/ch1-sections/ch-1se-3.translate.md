# عملگرها

عملگرها نحوهٔ انجام اعمال روی متغیرها و مقادیر هستند. قبلاً دو عملگر JavaScript دیدیم: `=` و `*`.

عملگر `*` ضرب ریاضی انجام می‌دهد. به اندازهٔ کافی ساده است، نه؟

عملگر `=` برای *assignment* استفاده می‌شود — ابتدا مقدار سمت *راست* (مقدار مبدأ) `=` را محاسبه می‌کنیم و سپس آن را در متغیری که سمت *چپ* (متغیر هدف) مشخص کرده‌ایم قرار می‌دهیم.

**Warning:** ممکن است ترتیب معکوس عجیبی برای مشخص کردن انتساب به نظر برسد. به‌جای `a = 42`، برخی ترجیح می‌دهند ترتیب را برعکس کنند تا مقدار مبدأ چپ و متغیر هدف راست باشد، مثل `42 -> a` (این JavaScript معتبر نیست!). متأسفانه، شکل مرتب‌شدهٔ `a = 42` و تغییرات مشابه در زبان‌های برنامه‌نویسی مدرن بسیار رایج است. اگر غیرطبیعی به نظر می‌رسد، فقط کمی وقت بگذارید و آن ترتیب را در ذهنتان تمرین کنید تا عادت کنید.

در نظر بگیرید:

```js
a = 2;
b = a + 1;
```

اینجا، مقدار `2` را به متغیر `a` انتساب می‌دهیم. سپس مقدار متغیر `a` را می‌گیریم (هنوز `2`)، `1` به آن اضافه می‌کنیم که مقدار `3` می‌شود، سپس آن مقدار را در متغیر `b` ذخیره می‌کنیم.

اگرچه از نظر فنی عملگر نیست، به کلمهٔ کلیدی `var` در هر برنامه نیاز دارید، چون راه اصلی *اعلام* (یعنی *ایجاد*) *متغیر*هاست (ببینید «Variables»).

همیشه باید متغیر را با نام قبل از استفاده اعلام کنید. اما فقط یک بار برای هر *scope* (ببینید «Scope») نیاز به اعلام دارید؛ بعد از آن می‌توانید هر چند بار که لازم است استفاده کنید. مثلاً:

```js
var a = 20;

a = a + 1;
a = a * 2;

console.log( a );	// 42
```

برخی از رایج‌ترین عملگرهای JavaScript:

* Assignment: `=` مثل `a = 2`.
* Math: `+` (جمع)، `-` (تفریق)، `*` (ضرب)، و `/` (تقسیم)، مثل `a * 3`.
* Compound Assignment: `+=`، `-=`، `*=`، و `/=` عملگرهای ترکیبی که عملیات ریاضی را با انتساب ترکیب می‌کنند، مثل `a += 2` (همان `a = a + 2`).
* Increment/Decrement: `++` (افزایش)، `--` (کاهش)، مثل `a++` (مشابه `a = a + 1`).
* Object Property Access: `.` مثل `console.log()`.

   اشیاء مقادیری هستند که مقادیر دیگر را در مکان‌های نام‌دار مشخص به نام properties نگه می‌دارند. `obj.a` یعنی مقدار object به نام `obj` با property به نام `a`. می‌توان به‌جای آن از `obj["a"]` برای دسترسی به properties استفاده کرد. فصل ۲ را ببینید.
* Equality: `==` (loose-equals)، `===` (strict-equals)، `!=` (loose not-equals)، `!==` (strict not-equals)، مثل `a == b`.

   «Values & Types» و فصل ۲ را ببینید.
* Comparison: `<` (کمتر از)، `>` (بیشتر از)، `<=` (کمتر یا loose-equals)، `>=` (بیشتر یا loose-equals)، مثل `a <= b`.

   «Values & Types» و فصل ۲ را ببینید.
* Logical: `&&` (and)، `||` (or)، مثل `a || b` که یا `a` *یا* `b` را انتخاب می‌کند.

   این عملگرها برای بیان conditionals ترکیبی استفاده می‌شوند (ببینید «Conditionals»)، مثل اگر یا `a` *یا* `b` true باشد.

**Note:** برای جزئیات بیشتر و پوشش عملگرهای ذکرنشده، «Expressions and Operators» MDN را ببینید (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_Operators).
