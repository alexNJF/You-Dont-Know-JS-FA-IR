# شما جاوااسکریپت را نمی‌دانید: Scope و Closures - ویرایش اول
# Scope واژگانی

در فصل ۱، «scope» را به‌عنوان مجموعه قوانینی تعریف کردیم که نحوهٔ جستجوی متغیر توسط *Engine* بر اساس نام شناسه و یافتن آن را، چه در *Scope* فعلی چه در هر *Nested Scope* که در آن قرار دارد، اداره می‌کند.

دو مدل غالب برای نحوهٔ کار scope وجود دارد. اولی به‌مراتب رایج‌ترین است و توسط اکثریت عظیم زبان‌های برنامه‌نویسی استفاده می‌شود. **Lexical Scope** نامیده می‌شود و آن را عمیقاً بررسی خواهیم کرد. مدل دیگر که هنوز توسط برخی زبان‌ها (مثل اسکریپت Bash، برخی حالت‌های Perl و غیره) استفاده می‌شود **Dynamic Scope** نامیده می‌شود.

Dynamic Scope در پیوست الف پوشش داده می‌شود. اینجا فقط برای مقایسه با Lexical Scope ذکر می‌کنم، که مدل scope است که JavaScript از آن استفاده می‌کند.
