# Traceur

گوگل پروژه‌ای به‌نام «Traceur» [^note-traceur] نگهداری می‌کند که دقیقاً وظیفهٔ transpile کردن ویژگی‌های ES6 به pre-ES6 (عمدتاً ES5، اما نه همه!) برای استفادهٔ عمومی دارد. کمیتهٔ TC39 به این ابزار (و دیگران) برای تست معناشناسی ویژگی‌هایی که مشخص می‌کنند تکیه می‌کند.

Traceur از تکهٔ ما چه تولید می‌کند؟ حدس زدید!

```js
{
	try {
		throw undefined;
	} catch (a) {
		a = 2;
		console.log( a );
	}
}

console.log( a );
```

پس با استفاده از چنین ابزارهایی، می‌توانیم شروع به بهره‌برداری از block scope کنیم صرف‌نظر از اینکه ES6 را هدف می‌گیریم یا نه، چون `try/catch` از روزهای ES3 وجود داشته (و این‌طور کار کرده).
