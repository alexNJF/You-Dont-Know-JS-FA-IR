# خلاصه

Scope مجموعه قوانینی است که تعیین می‌کند یک متغیر (شناسه) کجا و چگونه قابل جستجو است. این جستجو ممکن است برای انتساب به متغیر باشد، که ارجاع LHS (سمت چپ) است، یا ممکن است برای بازیابی مقدارش باشد، که ارجاع RHS (سمت راست) است.

ارجاع‌های LHS از عملیات انتساب ناشی می‌شوند. انتساب‌های مربوط به *Scope* می‌تواند با عملگر `=` یا با انتقال آرگومان‌ها به (انتساب به) پارامترهای تابع رخ دهد.

*Engine* JavaScript اول کد را کامپایل می‌کند قبل از اجرا، و در این کار، دستوراتی مثل `var a = 2;` را به دو مرحلهٔ مجزا تقسیم می‌کند:

1. اول، `var a` برای اعلام آن در آن *Scope*. این در ابتدا، قبل از اجرای کد انجام می‌شود.

2. بعد، `a = 2` برای جستجوی متغیر (ارجاع LHS) و انتساب به آن در صورت یافتن.

هر دو جستجوی ارجاع LHS و RHS از *Scope* در حال اجرا شروع می‌کنند، و در صورت نیاز (یعنی آنجا آنچه می‌خواهند را پیدا نکنند)، از *Scope* تو در تو بالا می‌روند، یک scope (طبقه) در هر بار، به دنبال شناسه، تا به global (طبقهٔ بالا) برسند و متوقف شوند، و یا پیدا کنند یا نکنند.

ارجاع‌های RHS برآورده‌نشده منجر به پرتاب `ReferenceError` می‌شوند. ارجاع‌های LHS برآورده‌نشده منجر به ایجاد خودکار و ضمنی global با آن نام می‌شوند (اگر در «Strict Mode» [^note-strictmode] نباشیم)، یا `ReferenceError` (اگر در «Strict Mode» [^note-strictmode] باشیم).

### پاسخ‌های آزمون

```js
function foo(a) {
	var b = a;
	return a + b;
}

var c = foo( 2 );
```

1. تمام جستجوهای LHS را شناسایی کنید (۳ تا هست!).

	**`c = ..`، `a = 2` (انتساب ضمنی پارامتر) و `b = ..`**

2. تمام جستجوهای RHS را شناسایی کنید (۴ تا هست!).

    **`foo(2..`، `= a;`، `a + ..` و `.. + b`**


[^note-strictmode]: MDN: [Strict Mode](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions_and_function_scope/Strict_mode)
