# خلاصه

ممکن است وسوسه شویم `var a = 2;` را یک دستور ببینیم، اما *Engine* JavaScript آن‌طور نمی‌بیند. آن را `var a` و `a = 2` به‌عنوان دو دستور مجزا می‌بیند، اولی وظیفهٔ فاز کامپایلر و دومی وظیفهٔ فاز اجرا.

آنچه منجر می‌شود این است که تمام اعلام‌ها در یک scope، صرف‌نظر از جایی که ظاهر می‌شوند، *اول* قبل از اجرای خود کد پردازش می‌شوند. می‌توانید این را به‌صورت اعلام‌ها (متغیرها و توابع) که به بالای scopeهای مربوطه «منتقل» می‌شوند تجسم کنید، که آن را «hoisting» می‌نامیم.

خود اعلام‌ها hoist می‌شوند، اما انتساب‌ها، حتی انتساب‌های function expressionها، hoist *نمی‌شوند*.

مراقب اعلام‌های تکراری باشید، به‌ویژه ترکیب بین اعلام‌های عادی var و اعلام‌های تابع — خطر در کمین است اگر چنین کنید!
