# SIMD

SIMD (مخفف Single instruction, multiple data) شکلی از «data parallelism» است، در مقابل «task parallelism» در Web Workerها. چون تمرکز اینجا موازی‌سازی تکه‌های منطق برنامه نیست، بلکه پردازش موازی چندین قطعه‌داده است.

در SIMD، parallelism را threadها نمی‌دهند. در عوض CPUهای مدرن با «vector»های عددی (شبیه آرایه‌های نوع‌تخصصی‌شده) و دستوراتی که روی همه‌ی اعداد به‌صورت موازی عمل می‌کنند این قابلیت را می‌دهند؛ یعنی عملیات low-level مبتنی بر instruction-level parallelism.

تلاش برای expose کردن SIMD به JavaScript عمدتاً توسط Intel پیش برده شده (در زمان نگارش توسط Mohammad Haghighat) با همکاری تیم‌های Firefox و Chrome. SIMD آن زمان در مسیر اولیه‌ی استانداردسازی بود و شانس خوبی داشت در بازنگری بعدی JavaScript (احتمالاً حوالی ES7) بیاید.

پیشنهاد SIMD در JavaScript این بود که نوع‌های برداری کوتاه و APIهای مربوطه را در اختیار JS بگذارد؛ روی سیستم‌های SIMD-enabled عملیات مستقیم به معادل CPU map شود، و روی سیستم‌های بدون SIMD هم shim غیرموازی fallback داشته باشد.

مزیت performance برای اپ‌های data-intensive (تحلیل سیگنال، عملیات ماتریسی گرافیک و...) با چنین ریاضیات موازی کاملاً واضح است.

شکل‌های اولیه‌ی API مربوط به SIMD در زمان نگارش متن چیزی شبیه این بود:

```js
var v1 = SIMD.float32x4( 3.14159, 21.0, 32.3, 55.55 );
var v2 = SIMD.float32x4( 2.1, 3.2, 4.3, 5.4 );

var v3 = SIMD.int32x4( 10, 101, 1001, 10001 );
var v4 = SIMD.int32x4( 10, 20, 30, 40 );

SIMD.float32x4.mul( v1, v2 );	// [ 6.597339, 67.2, 138.89, 299.97 ]
SIMD.int32x4.add( v3, v4 );		// [ 20, 121, 1031, 10041 ]
```

اینجا دو نوع داده‌ی برداری می‌بینید: اعشاری ۳۲بیتی و صحیح ۳۲بیتی. این vectorها دقیقاً ۴ عنصر ۳۲بیتی دارند چون با اندازه‌ی vectorهای SIMD (یعنی ۱۲۸ بیت) در بیشتر CPUهای مدرن منطبق‌اند. ممکن است در آینده نسخه‌های `x8` (یا حتی بزرگ‌تر) هم ببینیم.

غیر از `mul()` و `add()`، عملیات‌های زیاد دیگری هم احتمالاً اضافه می‌شوند، مثل `sub()`, `div()`, `abs()`, `neg()`, `sqrt()`, `reciprocal()`, `reciprocalSqrt()` (حسابی)، `shuffle()` (بازترازبندی عناصر بردار)، `and()`, `or()`, `xor()`, `not()` (منطقی)، `equal()`, `greaterThan()`, `lessThan()` (مقایسه)، `shiftLeft()`, `shiftRightLogical()`, `shiftRightArithmetic()` (شیفت)، و تبدیل‌هایی مثل `fromFloat32x4()` و `fromInt32x4()`.

**نکته:** یک "prollyfill" رسمی (polyfill امیدوارانه/آینده‌نگر) برای SIMD هم وجود داشته که قابلیت‌های برنامه‌ریزی‌شده‌ی بیشتری را نسبت به این بخش نشان می‌دهد.
