# Implementation Limits

مشخصات جاوااسکریپت محدودیت‌های دلخواه روی چیزهایی مثل تعداد آرگومان‌های یک تابع یا طول یک string literal قرار نمی‌دهد، اما این محدودیت‌ها به‌هرحال وجود دارند، به‌خاطر جزئیات پیاده‌سازی در موتورهای مختلف.

مثلاً:

```js
function addAll() {
	var sum = 0;
	for (var i=0; i < arguments.length; i++) {
		sum += arguments[i];
	}
	return sum;
}

var nums = [];
for (var i=1; i < 100000; i++) {
	nums.push(i);
}

addAll( 2, 4, 6 );				// 12
addAll.apply( null, nums );		// should be: 499950000
```

در بعضی موتورهای JS جواب درست `499950000` را می‌گیرید، اما در بقیه (مثل Safari 6.x) خطا می‌گیرید: «RangeError: Maximum call stack size exceeded.»

نمونه‌های دیگر محدودیت‌های شناخته‌شده:

* حداکثر تعداد کاراکتر مجاز در یک string literal (نه فقط مقدار string)
* اندازه (بایت) داده‌ای که می‌توان در آرگومان‌های فراخوانی تابع فرستاد (یعنی اندازهٔ stack)
* تعداد پارامترها در اعلام تابع
* حداکثر عمق call stack بهینه‌نشده (یعنی با بازگشت): طول زنجیرهٔ فراخوانی تابع از یکی به دیگری چقدر می‌تواند باشد
* تعداد ثانیه‌ای که یک برنامهٔ JS می‌تواند به‌طور مداوم مرورگر را block کند
* حداکثر طول مجاز برای نام یک متغیر
* ...

رسیدن به این محدودیت‌ها خیلی رایج نیست، اما باید آگاه باشید که محدودیت‌ها می‌توانند و وجود دارند، و مهم اینکه بین موتورها متفاوت‌اند.
