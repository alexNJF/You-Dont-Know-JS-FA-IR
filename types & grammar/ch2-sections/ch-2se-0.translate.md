# شما جاوااسکریپت را نمی‌دانید: Types و Grammar - ویرایش اول
# فصل ۲: Values

`array`ها، `string`ها و `number`ها پایه‌ترین بلوک‌های هر برنامه‌اند، اما JavaScript با این typeها ویژگی‌های منحصربه‌فردی دارد که ممکن است یا خوشایندتان باشد یا گیجتان کند.

بیایید چند type مقدار از پیش‌تعریف‌شده در JS را ببینیم و بررسی کنیم چطور می‌توانیم رفتار آن‌ها را بهتر درک و درست به کار بگیریم.
