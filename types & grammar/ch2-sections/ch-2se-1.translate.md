# Arrays

در مقایسه با زبان‌های type-enforced، `array`های JavaScript فقط ظرف هر نوع مقداری هستند، از `string` تا `number` تا `object` و حتی یک `array` دیگر (که به آرایه‌های چندبعدی منجر می‌شود).

```js
var a = [ 1, "2", [3] ];

a.length;		// 3
a[0] === 1;		// true
a[2][0] === 3;	// true
```

نیازی به از پیش تعیین اندازهٔ `array`ها نیست (به «Arrays» در فصل ۳ مراجعه کنید)، فقط آن‌ها را اعلان کنید و مقادیر را هرطور که می‌خواهید اضافه کنید:

```js
var a = [ ];

a.length;	// 0

a[0] = 1;
a[1] = "2";
a[2] = [ 3 ];

a.length;	// 3
```

**هشدار:** استفاده از `delete` روی مقدار `array` آن خانه را از `array` حذف می‌کند، اما حتی اگر آخرین عنصر را حذف کنید، property به‌نام `length` **به‌روز نمی‌شود**؛ مراقب باشید! خود عملگر `delete` را در فصل ۵ دقیق‌تر پوشش می‌دهیم.

در ساختن `array`های «sparse» (خالی یا با خانه‌های خالی/غایب) دقت کنید:

```js
var a = [ ];

a[0] = 1;
// no `a[1]` slot set here
a[2] = [ 3 ];

a[1];		// undefined

a.length;	// 3
```

هرچند کار می‌کند، می‌تواند به رفتار گیج‌کننده با «خانه‌های خالی» بین آن‌ها بینجامد. خانه ظاهراً مقدار `undefined` دارد، اما مثل وقتی که صریحاً مقداردهی شده باشد (`a[1] = undefined`) رفتار نمی‌کند. برای جزئیات بیشتر به «Arrays» در فصل ۳ مراجعه کنید.

`array`ها با اندیس عددی هستند (همان‌طور که انتظار دارید)، اما نکتهٔ ظریف این است که آن‌ها object هم هستند و می‌توان به آن‌ها کلید/propertyهای `string` اضافه کرد (که در `length` آرایه شمرده نمی‌شوند):

```js
var a = [ ];

a[0] = 1;
a["foobar"] = 2;

a.length;		// 1
a["foobar"];	// 2
a.foobar;		// 2
```

با این حال، یک نکتهٔ مهم: اگر مقدار `string`ی که به‌عنوان کلید منظور دارید بتواند به `number` مبنای ۱۰ استاندارد coerce شود، فرض بر این است که می‌خواستید از آن به‌عنوان اندیس `number` استفاده کنید، نه کلید `string`!

```js
var a = [ ];

a["13"] = 42;

a.length; // 14
```

به‌طور کلی اضافه کردن کلید/propertyهای `string` به `array`ها ایدهٔ خوبی نیست. از `object`ها برای نگهداری مقادیر در کلیدها/propertyها استفاده کنید و `array`ها را فقط برای مقادیر با اندیس عددی نگه دارید.

### Array-Likes

گاهی لازم است مقداری شبیه `array` (مجموعهٔ اندیس‌گذاری‌شدهٔ عددی) را به یک `array` واقعی تبدیل کنید، معمولاً تا بتوانید متدهای آرایه (مثل `indexOf(..)`، `concat(..)`، `forEach(..)` و غیره) را روی آن مجموعه فراخوانی کنید.

مثلاً خیلی از عملیات پرس‌وجوی DOM لیستی از المنت‌های DOM برمی‌گردانند که `array` واقعی نیستند اما برای هدف تبدیل ما به‌اندازهٔ کافی شبیه `array` هستند. مثال رایج دیگر وقتی است که توابع شیء `arguments` (شبیه آرایه؛ از ES6 منسوخ) را برای دسترسی به آرگومان‌ها به‌صورت لیست در معرض می‌گذارند.

یک راه بسیار رایج برای این تبدیل، قرض گرفتن متد `slice(..)` روی آن مقدار است:

```js
function foo() {
	var arr = Array.prototype.slice.call( arguments );
	arr.push( "bam" );
	console.log( arr );
}

foo( "bar", "baz" ); // ["bar","baz","bam"]
```

اگر `slice()` بدون پارامتر دیگر فراخوانی شود (مثل همین قطعه)، مقدار پیش‌فرض پارامترهایش در عمل آرایه (یا اینجا مقدار شبیه آرایه) را کپی می‌کند.

از ES6 به بعد، متد از پیش‌تعریف‌شدهٔ `Array.from(..)` هم همین کار را می‌کند:

```js
...
var arr = Array.from( arguments );
...
```

**توجه:** `Array.from(..)` قابلیت‌های قدرتمند زیادی دارد و در عنوان *ES6 & Beyond* این مجموعه به‌تفصیل پوشش داده می‌شود.
