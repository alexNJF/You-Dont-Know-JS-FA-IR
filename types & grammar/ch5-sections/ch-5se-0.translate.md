# شما جاوااسکریپت را نمی‌دانید: Types و Grammar - ویرایش اول
# فصل ۵: Grammar

آخرین موضوع مهمی که می‌خواهیم به آن بپردازیم این است که نحو (syntax) زبان جاوااسکریپت چطور کار می‌کند (که به آن grammar هم می‌گویند). شاید فکر کنید می‌دانید چطور JS بنویسید، اما در بخش‌های مختلف grammar زبان ظرافت‌های زیادی وجود دارد که به سردرگمی و تصور نادرست منجر می‌شوند؛ پس می‌خواهیم به آن بخش‌ها شیرجه بزنیم و چند نکته را روشن کنیم.

| NOTE: |
| :--- |
| اصطلاح «grammar» شاید برای خوانندگان کمتر از «syntax» آشنا باشد. از بسیاری جهات، این دو اصطلاح مشابه‌اند و *قواعد* کار زبان را توصیف می‌کنند. تفاوت‌های ظریفی وجود دارد، اما برای بحث ما اینجا بیشترشان مهم نیستند. grammar جاوااسکریپت روشی ساختاریافته برای توصیف این است که syntax (عملگرها، کلمات کلیدی و غیره) چطور در کنار هم قرار می‌گیرند و برنامه‌های درست و معتبر می‌سازند. به عبارت دیگر، بحث از syntax بدون grammar بسیاری از جزئیات مهم را حذف می‌کند. پس تمرکز ما در این فصل دقیق‌تر با عنوان *grammar* توصیف می‌شود، حتی اگر آنچه توسعه‌دهندگان مستقیماً با آن سروکار دارند خود syntax خام زبان باشد. |
