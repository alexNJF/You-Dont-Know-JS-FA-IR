# شما جاوااسکریپت را نمی‌دانید: Types و Grammar
# پیش‌گفتار

یک‌بار گفته شد: «JavaScript تنها زبانی است که توسعه‌دهندگان قبل از استفاده، یاد نمی‌گیرند.»

هر بار این نقل‌قول را می‌شنوم می‌خندم چون برای من درست بود و گمان می‌کنم برای بسیاری از توسعه‌دهندگان دیگر هم همین‌طور بوده است. JavaScript، و شاید حتی CSS و HTML، در روزهای اول اینترنت جزو زبان‌های اصلی علوم رایانهٔ تدریس‌شده در دانشگاه نبودند، پس رشد شخصی خیلی به جستجو و «مشاهدهٔ سورس» توسعه‌دهندهٔ نوپا برای کنار هم چیدن این زبان‌های پایهٔ وب وابسته بود.

هنوز اولین پروژهٔ وب‌سایت دبیرستانم را به یاد دارم. وظیفه این بود که هر نوع فروشگاه وب بسازیم، و من که طرفدار جیمز باند بودم، فروشگاه گلدنآی را ساختم. همه چیز داشت: آهنگ میدی تم گلدنآی در پس‌زمینه، نشانه‌گیری با JavaScript که دور موس می‌چرخید، و صدای شلیک با هر کلیک. Q از این شاهکار وب‌سایت افتخار می‌کرد.

این داستان را می‌گویم چون آن زمان همان کاری را کردم که بسیاری از توسعه‌دهندگان امروز می‌کنند: تکه‌های کد JavaScript را بدون اینکه بدانم واقعاً چه اتفاقی می‌افتد کپی و در پروژه‌ام paste می‌کردم. استفادهٔ گسترده از toolkitهای JavaScript مثل jQuery به نوعی خودشان این الگوی «یادنگرفتن» هستهٔ JavaScript را تداوم بخشیده‌اند.

استفاده از toolkitهای JavaScript را بد نمی‌دانم؛ بالاخره من عضو تیم MooTools هستم! اما دلیل قدرتمند بودن toolkitهای JavaScript این است که توسعه‌دهندگانشان اصول و «گیرها» را می‌دانند و آن‌ها را درخشان به کار می‌برند. با وجود سودمندی این toolkitها، دانستن مبانی زبان هنوز بسیار مهم است، و با کتاب‌هایی مثل مجموعهٔ *شما جاوااسکریپت را نمی‌دانید* کایل سیمپسون، دیگر بهانهای برای یادنگرفتن آن‌ها نیست.

*Types و Grammar*، سومین عنوان این مجموعه، نگاهی عالی به مبانی هستهٔ JavaScript است که copy و paste و toolkitهای JavaScript آن‌ها را نمی‌آموزند و هرگز نمی‌توانند بیاموزند. Coercion و دام‌هایش، natives به‌عنوان constructor، و طیف کامل مبانی JavaScript با مثال‌های کد متمرکز به‌طور کامل توضیح داده شده‌اند. مثل بقیهٔ کتاب‌های این مجموعه، کایل مستقیم سر اصل مطلب می‌رود: بدون حاشیه و بازی با کلمات — دقیقاً نوع کتاب فنی که دوست دارم.

از Types و Grammar لذت ببرید و نگذارید زیاد از میزتان دور شود!
