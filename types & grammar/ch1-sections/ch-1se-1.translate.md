# Built-in Types

JavaScript هفت type از پیش‌تعریف‌شده دارد:

* `null`
* `undefined`
* `boolean`
* `number`
* `string`
* `object`
* `symbol` — از ES6 اضافه شد!

**توجه:** همهٔ این typeها به‌جز `object` «primitives» نامیده می‌شوند.

عملگر `typeof` نوع مقدار داده‌شده را بررسی می‌کند و همیشه یکی از هفت مقدار رشته برمی‌گرداند — به‌طور غافلگیرکننده‌ای با هفت type از پیش‌تعریف‌شدهٔی که فهرست کردیم تطابق یک‌به‌یک دقیق ندارد.

```js
typeof undefined     === "undefined"; // true
typeof true          === "boolean";   // true
typeof 42            === "number";    // true
typeof "42"          === "string";    // true
typeof { life: 42 }  === "object";    // true

// added in ES6!
typeof Symbol()      === "symbol";    // true
```

این شش type فهرست‌شده مقادیر نوع متناظر را دارند و همان‌طور که نشان داده شد مقدار رشتهٔ هم‌نام برمی‌گردانند. `Symbol` از ES6 یک نوع دادهٔ جدید است و در فصل ۳ پوشش داده می‌شود.

شاید متوجه شده باشید که `null` را از فهرست بالا حذف کردم. *خاص* است — خاص از این نظر که در ترکیب با عملگر `typeof` باگی دارد:

```js
typeof null === "object"; // true
```

خوب بود (و درست!) اگر `"null"` برمی‌گرداند، اما این باگ اولیهٔ JS حدود دو دهه پایدار مانده و احتمالاً هرگز اصلاح نمی‌شود چون محتوای وب موجود زیادی به رفتار باگی آن وابسته است و «اصلاح» باگ *باعث* «باگ»های بیشتر و شکستن خیلی از نرم‌افزارهای وب می‌شد.

اگر می‌خواهید مقدار `null` را با type آن تست کنید، به یک شرط مرکب نیاز دارید:

```js
var a = null;

(!a && typeof a === "object"); // true
```

`null` تنها مقدار primitive است که «falsy» (یعنی شبیه false؛ فصل ۴ را ببینید) است اما از بررسی `typeof` هم `"object"` برمی‌گرداند.

پس هفتمین مقدار رشته‌ای که `typeof` می‌تواند برگرداند چیست؟

```js
typeof function a(){ /* .. */ } === "function"; // true
```

راحت است فکر کنیم `function` یک type از پیش‌تعریف‌شدهٔ سطح بالا در JS است، به‌ویژه با این رفتار عملگر `typeof`. اما اگر مشخصات را بخوانید، می‌بینید در واقع یک «subtype» از object است. به‌طور مشخص، تابع به‌عنوان «callable object» شناخته می‌شود — شیئی که یک ویژگی داخلی `[[Call]]` دارد که اجازهٔ فراخوانی آن را می‌دهد.

اینکه توابع در واقع object هستند بسیار سودمند است. مهم‌تر از همه، می‌توانند property داشته باشند. مثلاً:

```js
function a(b,c) {
	/* .. */
}
```

شیء تابع یک property به نام `length` دارد که برابر تعداد پارامترهای رسمی اعلان‌شده است.

```js
a.length; // 2
```

چون تابع را با دو پارامتر رسمی نام‌دار (`b` و `c`) اعلان کردید، «طول تابع» برابر `2` است.

آرایه‌ها چطور؟ آن‌ها در JS native هستند، پس آیا type خاصی‌اند؟

```js
typeof [1,2,3] === "object"; // true
```

نه، فقط object. درست‌تر این است که آن‌ها را هم «subtype» از object بدانیم (فصل ۳ را ببینید)، در این مورد با ویژگی‌های اضافیِ اندیس‌گذاری عددی (در مقابل فقط کلید رشته‌ای مثل objectهای ساده) و نگهداری خودکار property به‌نام `.length`.
