## مقادیر BigInteger

چون حداکثر integer امن در `number`های JS برابر `9007199254740991` است (بالا ببینید)، چنین حد نسبتاً پایینی می‌تواند مشکل ایجاد کند اگر برنامهٔ JS نیاز به انجام ریاضی integer بزرگ‌تر داشته باشد، یا حتی فقط مقادیری مثل شناسه‌های integer ۶۴ بیتی (مثلاً شناسه‌های توییت توییتر) نگه دارد.

به همین دلیل، JS نوع جایگزین `bigint` (BigInteger) ارائه می‌دهد که می‌تواند integerهای به‌طور دلخواه بزرگ ذخیره کند (از نظر نظری محدود نیست، به‌جز حافظهٔ محدود ماشین و/یا پیاده‌سازی JS).

برای تمایز `bigint` از مقدار `number` صحیح (integer)، که در غیر این صورت هر دو یکسان به‌نظر می‌رسند (`42`)، JS به پسوند `n` روی مقادیر `bigint` نیاز دارد:

```js
myAge = 42n;        // این bigint است، نه number

myKidsAge = 11;     // این number است، نه bigint
```

بی‌مرزی بالای `bigint` را نشان می‌دهیم:

```js
Number.MAX_SAFE_INTEGER;        // 9007199254740991

Number.MAX_SAFE_INTEGER + 2;    // 9007199254740992 -- اوه!

myBigInt = 9007199254740991n;

myBigInt + 2n;                  // 9007199254740993n -- پhew!

myBigInt ** 2n;                 // 81129638414606663681390495662081n
```

همان‌طور که می‌بینید، نوع مقدار `bigint` می‌تواند حسابی دقیق بالای حد integer نوع مقدار `number` انجام دهد.

| WARNING: |
| :--- |
| توجه کنید عملگر `+` به `.. + 2n` به‌جای فقط `.. + 2` نیاز داشت؟ نمی‌توانید انواع مقدار `number` و `bigint` را در همان عبارت ترکیب کنید. این محدودیت آزاردهنده است، اما برنامهٔ شما را از عملیات ریاضی نامعتبری که نتایج غیرمنتظرهٔ غیرواضح می‌دادند محافظت می‌کند. |

مقدار `bigint` را می‌توان با تابع `BigInt(..)` هم ساخت؛ مثلاً، برای تبدیل مقدار `number` صحیح (integer) به `bigint`:

```js
myAge = 42n;

inc = 1;

myAge += BigInt(inc);

myAge;              // 43n
```

| WARNING: |
| :--- |
| اگرچه ممکن است برای برخی خوانندگان ضدشهودی به‌نظر برسد، `BigInt(..)` *همیشه* بدون کلمهٔ کلیدی `new` فراخوانی می‌شود. اگر از `new` استفاده شود، استثنا پرتاب می‌شود. |

این قطعاً یکی از رایج‌ترین کاربردهای تابع `BigInt(..)` است: تبدیل `number`ها به `bigint`ها، برای اهداف عملیات ریاضی.

اما غیرمعمول نیست که مقادیر integer بزرگ را به‌صورت رشته نمایش دهیم، به‌ویژه اگر آن مقادیر از محیط‌های زبان دیگر به محیط JS می‌آیند، یا از طریق قالب‌های مبادلهٔ خاصی که خودشان از مقادیر سبک `bigint` پشتیبانی نمی‌کنند.

بنابراین، `BigInt(..)` برای تبدیل اجباری آن مقادیر رشته به `bigint`ها مفید است:

```js
myBigInt = BigInt("12345678901234567890");

myBigInt;                       // 12345678901234567890n
```

برخلاف `parseInt(..)`، اگر هر کاراکتری در رشته غیرعددی باشد (ارقام `0-9` یا `-`)، از جمله `.` یا حتی کاراکتر پسوند `n` دنباله‌دار، استثنا پرتاب می‌شود. به عبارت دیگر، `BigInt(..)` تبدیل اجباری همه‌یاهیچ است، نه تبدیل تجزیه‌ای.
