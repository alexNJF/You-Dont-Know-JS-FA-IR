## مقادیر بولی

نوع `boolean` دو مقدار دارد: `false` و `true`.

در «روزهای قدیم»، زبان‌های برنامه‌نویسی طبق قرارداد از `0` برای `false` و `1` برای `true` استفاده می‌کردند. پس می‌توانید نوع `boolean` و کلمات کلیدی `false` و `true` را به‌عنوان شکر معنایی راحت روی مقادیر `0` و `1` در نظر بگیرید:

```js
// isLoggedIn = 1;
isLoggedIn = true;

isComplete = 0;
// isComplete = false;
```

مقادیر بولی نحوهٔ تمام تصمیم‌گیری‌ها در برنامهٔ JS هستند:

```js
if (isLoggedIn) {
    // کاری انجام بده
}

while (!isComplete) {
    // ادامه بده
}
```

عملگر `!` مقدار بولی را نفی/معکوس می‌کند: `false` به `true` و `true` به `false` می‌شود.
