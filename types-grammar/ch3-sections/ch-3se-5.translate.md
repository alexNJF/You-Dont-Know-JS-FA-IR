## Arrays

آرایه‌ها اشیائی هستند که تخصص‌یافته برای رفتار به‌عنوان مجموعه‌های ایندکس‌شدهٔ عددی از مقادیر، در مقابل نگه‌داشتن مقادیر در ویژگی‌های نام‌دار مثل plain objects.

آرایه‌ها شکل literal دارند:

```js
favoriteNumbers = [ 3, 12, 42 ];

favoriteNumbers[2];                 // 42
```

همان آرایه را می‌شد با constructorٔ `new Array()` به‌صورت دستوری هم تعریف کرد:

```js
favoriteNumbers = new Array();
favoriteNumbers[0] = 3;
favoriteNumbers[1] = 12;
favoriteNumbers[2] = 42;
```

آرایه‌ها با `[[Prototype]]` به `Array.prototype` پیوند دارند و دسترسی تفویض‌شده به انواع متدهای آرایه‌محور می‌دهند، مثل `map(..)`، `includes(..)` و غیره:

```js
favoriteNumbers.map(v => v * 2);
// [ 6, 24, 84 ]

favoriteNumbers.includes(42);       // true
```

برخی متدهای تعریف‌شده روی `Array.prototype` — مثلاً `push(..)`، `pop(..)`، `sort(..)` و غیره — با تغییر مقدار آرایه در جا رفتار می‌کنند. متدهای دیگر — مثلاً `concat(..)`، `map(..)`، `slice(..)` — با ایجاد آرایهٔ جدید برای برگرداندن رفتار می‌کنند و آرایهٔ اصلی را دست‌نخورده می‌گذارند. دستهٔ سوم توابع آرایه — مثلاً `indexOf(..)`، `includes(..)` و غیره — صرفاً محاسبه و برگرداندن نتیجهٔ (غیرآرایه) می‌کنند.
