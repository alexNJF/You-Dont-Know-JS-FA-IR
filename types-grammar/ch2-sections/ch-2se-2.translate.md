## انتساب‌های اولیه

هر انتساب مقدار اولیه از یک متغیر/نگه‌دارنده به دیگری *value-copy* است:

```js
myAge = 42;

yourAge = myAge;        // انتساب با value-copy

myAge;                  // 42
yourAge;                // 42
```

اینجا، متغیرهای `myAge` و `yourAge` هر کدام کپی خودشان از مقدار عددی `42` را دارند.

| NOTE: |
| :--- |
| داخل موتور JS، *ممکن است* فقط یک مقدار `42` در حافظه وجود داشته باشد و موتور هر دو متغیر `myAge` و `yourAge` را به مقدار مشترک اشاره دهد. چون مقادیر اولیه immutable هستند، خطری در انجام این کار توسط موتور JS نیست. اما آنچه برای ما به‌عنوان توسعه‌دهندگان JS مهم است این است که در برنامه‌هایمان، `myAge` و `yourAge` طوری عمل می‌کنند انگار کپی خودشان از آن مقدار را دارند، نه اینکه آن را به‌اشتراک بگذارند. |

اگر بعداً `myAge` را به `43` دوباره انتساب دهیم (وقتی تولدم است)، بر `42` که هنوز به `yourAge` اختصاص داده شده تأثیر نمی‌گذارد:

```js
myAge++;            // تقریباً مثل: myAge = myAge + 1

myAge;              // 43
yourAge;            // 42 <-- بدون تغییر
```
