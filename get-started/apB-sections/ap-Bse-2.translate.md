# تمرین Closure

حالا با closure (فصل ۴، ستون ۱) تمرین کنیم.

تابع `range(..)` عددی را به‌عنوان argument اول می‌گیرد، که اولین عدد در محدودهٔ مورد نظر اعداد را نشان می‌دهد. argument دوم هم عددی است که پایان محدودهٔ مورد نظر (شامل) را نشان می‌دهد. اگر argument دوم حذف شود، باید تابع دیگری برگردانده شود که آن argument را انتظار دارد.

```js
function range(start,end) {
    // ..TODO..
}

range(3,3);    // [3]
range(3,8);    // [3,4,5,6,7,8]
range(3,0);    // []

var start3 = range(3);
var start4 = range(4);

start3(3);     // [3]
start3(8);     // [3,4,5,6,7,8]
start3(0);     // []

start4(6);     // [4,5,6]
```

ابتدا خودتان حل کنید.
