# مقایسهٔ شرطی Coercive

بله، آن نام بخش دهان‌پرکن است. اما دربارهٔ چه صحبت می‌کنیم؟ دربارهٔ expressionهای شرطی که برای تصمیم‌گیری نیاز به انجام مقایسه‌های coercion-oriented دارند.

دستورات `if` و ternary `? :`، و همچنین clauseهای test در حلقه‌های `while` و `for`، همگی مقایسهٔ مقدار ضمنی انجام می‌دهند. اما از چه نوعی؟ «strict» یا «coercive»؟ در واقع هر دو.

در نظر بگیرید:

```js
var x = 1;

if (x) {
    // اجرا می‌شود!
}

while (x) {
    // یک بار اجرا می‌شود!
    x = false;
}
```

شاید این expressionهای شرطی `(x)` را این‌طور فکر کنید:

```js
var x = 1;

if (x == true) {
    // اجرا می‌شود!
}

while (x == true) {
    // یک بار اجرا می‌شود!
    x = false;
}
```

در این مورد خاص—مقدار `x` برابر `1`—آن مدل ذهنی کار می‌کند، اما به‌طور گسترده‌تر دقیق نیست. در نظر بگیرید:

```js
var x = "hello";

if (x) {
    // اجرا می‌شود!
}

if (x == true) {
    // اجرا نمی‌شود :(
}
```

اوه. پس دستور `if` واقعاً چه می‌کند؟ این مدل ذهنی دقیق‌تر است:

```js
var x = "hello";

if (Boolean(x) == true) {
    // اجرا می‌شود
}

// که همان است با:

if (Boolean(x) === true) {
    // اجرا می‌شود
}
```

چون تابع `Boolean(..)` همیشه مقداری از نوع boolean برمی‌گرداند، `==` در مقابل `===` در این تکه نامربوط است؛ هر دو همان کار را می‌کنند. اما بخش مهم دیدن این است که قبل از مقایسه، coercion رخ می‌دهد، از هر نوعی که `x` فعلاً است، به boolean.

نمی‌توانید از coercionها در مقایسه‌های جاوااسکریپت فرار کنید. محکم بگیرید و آن‌ها را یاد بگیرید.
