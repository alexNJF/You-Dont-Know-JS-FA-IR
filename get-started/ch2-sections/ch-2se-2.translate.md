# مقادیر

اساسی‌ترین واحد اطلاعات در یک برنامه مقدار است. مقادیر داده هستند. نحوهٔ حفظ state توسط برنامه هستند. مقادیر در جاوااسکریپت به دو شکل می‌آیند: **primitive** و **object**.

مقادیر با *literal*ها در برنامه‌ها جاسازی می‌شوند:

```js
greeting("My name is Kyle.");
```

در این برنامه، مقدار `"My name is Kyle."` یک string literal اولیه است؛ stringها مجموعه‌های مرتب کاراکترها هستند، معمولاً برای نمایش کلمات و جملات استفاده می‌شوند.

از کاراکتر double-quote `"` برای *delimit* کردن (احاطه، جدا، تعریف) مقدار string استفاده کردم. اما می‌توانستم از کاراکتر single-quote `'` هم استفاده کنم. انتخاب کدام کاراکتر quote کاملاً سبکی است. چیز مهم، برای خوانایی و نگهداری کد، انتخاب یکی و استفادهٔ یکنواخت از آن در کل برنامه است.

گزینهٔ دیگر برای delimit کردن string literal استفاده از کاراکتر back-tick `` ` `` است. با این حال، این انتخاب صرفاً سبکی نیست؛ تفاوت رفتاری هم هست. در نظر بگیرید:

```js
console.log("My name is ${ firstName }.");
// My name is ${ firstName }.

console.log('My name is ${ firstName }.');
// My name is ${ firstName }.

console.log(`My name is ${ firstName }.`);
// My name is Kyle.
```

با فرض اینکه این برنامه قبلاً متغیر `firstName` را با مقدار string `"Kyle"` تعریف کرده، string محدودشده با `` ` `` سپس expression متغیر (نشان‌داده‌شده با `${ .. }`) را به مقدار فعلی‌اش resolve می‌کند. این **interpolation** نامیده می‌شود.

string محدودشده با back-tick `` ` `` می‌تواند بدون شامل کردن expressionهای interpolated استفاده شود، اما این کل هدف آن نحو string literal جایگزین را باطل می‌کند:

```js
console.log(
    `Am I confusing you by omitting interpolation?`
);
// Am I confusing you by omitting interpolation?
```

رویکرد بهتر استفاده از `"` یا `'` است (باز هم، یکی را انتخاب کنید و پایبند بمانید!) برای stringها *مگر اینکه* interpolation نیاز داشته باشید؛ `` ` `` را فقط برای stringهایی که expressionهای interpolated شامل می‌کنند رزرو کنید.

غیر از stringها، برنامه‌های جاوااسکریپت اغلب literalهای اولیهٔ دیگر مثل boolean و number دارند:

```js
while (false) {
    console.log(3.141592);
}
```

`while` نوع حلقه را نشان می‌دهد، روشی برای تکرار عملیات *در حالی که* شرطش true است.

در این مورد، حلقه هرگز اجرا نمی‌شود (و هیچ چیز چاپ نمی‌شود)، چون از مقدار boolean `false` به‌عنوان شرط حلقه استفاده کردیم. `true` منجر به حلقه‌ای می‌شد که تا ابد ادامه می‌یافت، پس مراقب باشید!

عدد `3.141592`، همان‌طور که می‌دانید، تقریبی از PI ریاضی تا شش رقم اول است. با این حال، به‌جای جاسازی چنین مقداری، معمولاً از مقدار از پیش تعریف‌شدهٔ `Math.PI` برای آن منظور استفاده می‌کنید. تنوع دیگر روی اعداد نوع اولیهٔ `bigint` (عدد صحیح بزرگ) است، که برای ذخیرهٔ اعداد دلخواه بزرگ استفاده می‌شود.

اعداد اغلب در برنامه‌ها برای شمارش مراحل استفاده می‌شوند، مثل تکرارهای حلقه، و دسترسی به اطلاعات در موقعیت‌های عددی (یعنی index آرایه). آرایه‌ها/اشیاء را کمی بعد پوشش می‌دهیم، اما به‌عنوان مثال، اگر آرایه‌ای به نام `names` بود، می‌توانستیم عنصر در موقعیت دومش را این‌طور دسترسی دهیم:

```js
console.log(`My name is ${ names[1] }.`);
// My name is Kyle.
```

از `1` برای عنصر در موقعیت دوم استفاده کردیم، به‌جای `2`، چون مثل بیشتر زبان‌های برنامه‌نویسی، indexهای آرایهٔ جاوااسکریپت از ۰ شروع می‌شوند (`0` موقعیت اول است).

علاوه بر stringها، اعداد و booleanها، دو مقدار *primitive* دیگر در برنامه‌های جاوااسکریپت `null` و `undefined` هستند. در حالی که تفاوت‌هایی بین آن‌ها هست (برخی تاریخی و برخی معاصر)، در بیشتر موارد هر دو مقدار هدف نشان دادن *خالی بودن* (یا عدم وجود) یک مقدار را دارند.

بسیاری توسعه‌دهندگان ترجیح می‌دهند هر دو را به‌طور یکنواخت این‌طور برخورد کنند، یعنی فرض می‌شود مقادیر غیرقابل تشخیص باشند. اگر دقت شود، اغلب ممکن است. با این حال، امن‌ترین و بهترین راه استفادهٔ منحصراً از `undefined` به‌عنوان مقدار خالی واحد است، حتی با وجود اینکه `null` جذاب به نظر می‌رسد چون کوتاه‌تر تایپ می‌شود!

```js
while (value != undefined) {
    console.log("Still got something!");
}
```

آخرین مقدار اولیهٔ قابل‌توجه symbol است، که مقداری با هدف خاص است که مثل مقدار پنهان و غیرقابل‌حدس رفتار می‌کند. Symbolها تقریباً منحصراً به‌عنوان کلیدهای خاص روی اشیاء استفاده می‌شوند:

```js
hitchhikersGuide[ Symbol("meaning of life") ];
// 42
```

استفادهٔ مستقیم از symbolها را در برنامه‌های معمول جاوااسکریپت زیاد نمی‌بینید. عمدتاً در کد سطح پایین مثل کتابخانه‌ها و فریمورک‌ها استفاده می‌شوند.

## آرایه‌ها و اشیاء

علاوه بر primitiveها، نوع مقدار دیگر در جاوااسکریپت مقدار object است.

همان‌طور که قبلاً ذکر شد، آرایه‌ها نوع خاصی از object هستند که از لیست دادهٔ مرتب و با index عددی تشکیل شده‌اند:

```js
var names = [ "Frank", "Kyle", "Peter", "Susan" ];

names.length;
// 4

names[0];
// Frank

names[1];
// Kyle
```

آرایه‌های جاوااسکریپت می‌توانند هر نوع مقداری را نگه دارند، primitive یا object (از جمله آرایه‌های دیگر). همان‌طور که toward پایان فصل ۳ خواهیم دید، حتی توابع مقادیری هستند که می‌توانند در آرایه‌ها یا اشیاء نگه داشته شوند.

| نکته: |
| :--- |
| توابع، مثل آرایه‌ها، نوع خاصی (با نام مستعار sub-type) از object هستند. توابع را کمی بعد با جزئیات بیشتر پوشش می‌دهیم. |

اشیاء عمومی‌ترند: مجموعه‌ای بدون ترتیب و کلیددار از هر مقدار متنوع. به عبارت دیگر، عنصر را با نام موقعیت string (با نام مستعار «key» یا «property») دسترسی می‌دهید به‌جای موقعیت عددی (مثل آرایه‌ها). مثلاً:

```js
var me = {
    first: "Kyle",
    last: "Simpson",
    age: 39,
    specialties: [ "JS", "Table Tennis" ]
};

console.log(`My name is ${ me.first }.`);
```

اینجا `me` یک object را نشان می‌دهد، و `first` نام موقعیت اطلاعات در آن object (مجموعهٔ مقدار) را نشان می‌دهد. گزینهٔ نحو دیگر که اطلاعات را در object با property/key آن دسترسی می‌دهد از براکت‌های مربعی `[ ]` استفاده می‌کند، مثل `me["first"]`.

## تعیین نوع مقدار

برای تشخیص مقادیر، عملگر `typeof` نوع built-in آن را می‌گوید، اگر primitive باشد، یا در غیر این صورت `"object"`:

```js
typeof 42;                  // "number"
typeof "abc";               // "string"
typeof true;                // "boolean"
typeof undefined;           // "undefined"
typeof null;                // "object" -- اوه، باگ!
typeof { "a": 1 };          // "object"
typeof [1,2,3];             // "object"
typeof function hello(){};  // "function"
```

| هشدار: |
| :--- |
| متأسفانه `typeof null` به‌جای `"null"` مورد انتظار، `"object"` برمی‌گرداند. همچنین `typeof` برای توابع `"function"` خاص برمی‌گرداند، اما برای آرایه‌ها `"array"` مورد انتظار را نه. |

تبدیل از یک نوع مقدار به نوع دیگر، مثل از string به number، در جاوااسکریپت «coercion» نامیده می‌شود. این را با جزئیات بیشتر بعداً در این فصل پوشش می‌دهیم.

مقادیر primitive و object هنگام assign یا pass شدن رفتار متفاوتی دارند. این جزئیات را در پیوست A، «Values vs References» پوشش می‌دهیم.
