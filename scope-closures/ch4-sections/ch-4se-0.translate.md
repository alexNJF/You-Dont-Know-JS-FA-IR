# هنوز جاوااسکریپت را نمی‌شناسید: Scope و Closures - ویرایش دوم
# فصل ۴: پیرامون Scope سراسری

فصل ۳ چند بار «scope سراسری» را ذکر کرد، اما شاید هنوز تعجب کنید چرا scope بیرونی‌ترین یک برنامه در جاوااسکریپت مدرن اینقدر مهم است. اکثریت عظیم کار اکنون داخل توابع و ماژول‌ها انجام می‌شود به‌جای سراسری.

آیا کافی است فقط ادعا کنیم «از scope سراسری اجتناب کنید» و تمام؟

scope سراسری یک برنامهٔ جاوااسکریپت موضوعی غنی است، با کاربرد و ظرافت بسیار بیشتر از آنچه احتمالاً فرض می‌کنید. این فصل ابتدا کاوش می‌کند scope سراسری چگونه (هنوز) برای نوشتن برنامه‌های جاوااسکریپت امروزی مفید و مرتبط است، سپس به تفاوت‌ها در *کجا* و *چگونه دسترسی* به scope سراسری در محیط‌های مختلف جاوااسکریپت می‌پردازد.

درک کامل scope سراسری برای تسلط شما بر استفاده از lexical scope برای ساختاردهی برنامه‌هایتان حیاتی است.
