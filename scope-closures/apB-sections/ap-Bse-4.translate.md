# Closure (بخش ۳)

در این تمرین سوم و نهایی روی closure، یک ماشین‌حساب پایه پیاده‌سازی می‌کنیم. تابع `calculator()` نمونه‌ای از ماشین‌حساب تولید می‌کند که حالت خودش را به شکل تابع (`calc(..)`، زیر) نگه می‌دارد:

```js
function calculator() {
    // ..
}

var calc = calculator();
```

هر بار `calc(..)` فراخوانی می‌شود، یک کاراکتر واحد می‌فرستید که نشان‌دهنده فشار دکمه ماشین‌حساب است. برای ساده‌تر نگه داشتن، ماشین‌حساب را به ورود فقط رقم‌ها (۰–۹)، عملیات حسابی (+, -, \*, /) و «=» برای محاسبه عملیات محدود می‌کنیم. عملیات‌ها به ترتیب واردشده پردازش می‌شوند؛ هیچ گروه‌بندی «( )» یا اولویت عملگر نیست.

ورود اعشار را پشتیبانی نمی‌کنیم، اما عملیات تقسیم می‌تواند آن‌ها را نتیجه دهد. ورود اعداد منفی را پشتیبانی نمی‌کنیم، اما عملیات «-» می‌تواند آن‌ها را نتیجه دهد. پس باید بتوانید با اول وارد کردن عملیاتی برای محاسبه آن هر عدد منفی یا اعشاری تولید کنید. سپس می‌توانید با آن مقدار به محاسبه ادامه دهید.

برگشت فراخوانی‌های `calc(..)` باید آنچه روی ماشین‌حساب واقعی نمایش داده می‌شد را تقلید کند، مثل منعکس کردن آنچه تازه فشار داده شد، یا محاسبه کل هنگام فشار «=».

مثلاً:

```js
calc("4");     // 4
calc("+");     // +
calc("7");     // 7
calc("3");     // 3
calc("-");     // -
calc("2");     // 2
calc("=");     // 75
calc("*");     // *
calc("4");     // 4
calc("=");     // 300
calc("5");     // 5
calc("-");     // -
calc("5");     // 5
calc("=");     // 0
```

چون این استفاده کمی دست‌وپاگیر است، این helper `useCalc(..)` ماشین‌حساب را با کاراکترها یکی یکی از یک رشته اجرا می‌کند و display را هر بار محاسبه می‌کند:

```js
function useCalc(calc,keys) {
    return [...keys].reduce(
        function showDisplay(display,key){
            var ret = String( calc(key) );
            return (
                display +
                (
                  (ret != "" && key == "=") ?
                      "=" :
                      ""
                ) +
                ret
            );
        },
        ""
    );
}

useCalc(calc,"4+3=");           // 4+3=7
useCalc(calc,"+9=");            // +9=16
useCalc(calc,"*8=");            // *5=128
useCalc(calc,"7*2*3=");         // 7*2*3=42
useCalc(calc,"1/0=");           // 1/0=ERR
useCalc(calc,"+3=");            // +3=ERR
useCalc(calc,"51=");            // 51
```

منطقی‌ترین استفاده از این helper `useCalc(..)` این است که همیشه «=» آخرین کاراکتر واردشده باشد.

برخی از قالب‌بندی کل‌های نمایش‌داده‌شده توسط ماشین‌حساب نیاز به برخورد خاص دارند. این تابع `formatTotal(..)` را ارائه می‌دهم که ماشین‌حساب باید هر وقت می‌خواهد کل محاسبه‌شده فعلی را برگرداند (بعد از وارد شدن «=») استفاده کند:

```js
function formatTotal(display) {
    if (Number.isFinite(display)) {
        // constrain display to max 11 chars
        let maxDigits = 11;
        // reserve space for "e+" notation?
        if (Math.abs(display) > 99999999999) {
            maxDigits -= 6;
        }
        // reserve space for "-"?
        if (display < 0) {
            maxDigits--;
        }

        // whole number?
        if (Number.isInteger(display)) {
            display = display
                .toPrecision(maxDigits)
                .replace(/\.0+$/,"");
        }
        // decimal
        else {
            // reserve space for "."
            maxDigits--;
            // reserve space for leading "0"?
            if (
                Math.abs(display) >= 0 &&
                Math.abs(display) < 1
            ) {
                maxDigits--;
            }
            display = display
                .toPrecision(maxDigits)
                .replace(/0+$/,"");
        }
    }
    else {
        display = "ERR";
    }
    return display;
}
```

نگران نحوه کار `formatTotal(..)` نباشید. بیشتر منطقش انبوهی از برخورد برای محدود کردن display ماشین‌حساب به حداکثر ۱۱ کاراکتر است، حتی اگر منفی‌ها، اعشار تکراری یا حتی نماد نمایی «e+» لازم باشد.

دوباره، خیلی در گل رفتار خاص ماشین‌حساب گیر نکنید. روی *حافظه* closure تمرکز کنید.

خودتان تمرین را امتحان کنید، سپس راه‌حل پیشنهادی را در انتهای این پیوست ببینید.
