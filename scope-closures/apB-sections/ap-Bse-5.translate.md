# ماژول‌ها

این تمرین تبدیل ماشین‌حساب از Closure (بخش ۳) به ماژول است.

قابلیت اضافی به ماشین‌حساب اضافه نمی‌کنیم، فقط رابطش را تغییر می‌دهیم. به جای فراخوانی یک تابع واحد `calc(..)`، متدهای خاصی روی API عمومی برای هر «فشار کلید» ماشین‌حسابمان فراخوانی می‌کنیم. خروجی‌ها همان می‌مانند.

این ماژول باید به عنوان تابع کارخانه ماژول کلاسیک به نام `calculator()` بیان شود، به جای IIFE singleton، تا در صورت تمایل چند ماشین‌حساب ایجاد شوند.

API عمومی باید این متدها را شامل شود:

* `number(..)` (ورودی: کاراکتر/عدد «فشارداده‌شده»)
* `plus()`
* `minus()`
* `mult()`
* `div()`
* `eq()`

استفاده این‌طور خواهد بود:

```js
var calc = calculator();

calc.number("4");     // 4
calc.plus();          // +
calc.number("7");     // 7
calc.number("3");     // 3
calc.minus();         // -
calc.number("2");     // 2
calc.eq();            // 75
```

`formatTotal(..)` از تمرین قبلی همان می‌ماند. اما helper `useCalc(..)` باید برای کار با API ماژول تنظیم شود:

```js
function useCalc(calc,keys) {
    var keyMappings = {
        "+": "plus",
        "-": "minus",
        "*": "mult",
        "/": "div",
        "=": "eq"
    };

    return [...keys].reduce(
        function showDisplay(display,key){
            var fn = keyMappings[key] || "number";
            var ret = String( calc[fn](key) );
            return (
                display +
                (
                  (ret != "" && key == "=") ?
                      "=" :
                      ""
                ) +
                ret
            );
        },
        ""
    );
}

useCalc(calc,"4+3=");           // 4+3=7
useCalc(calc,"+9=");            // +9=16
useCalc(calc,"*8=");            // *5=128
useCalc(calc,"7*2*3=");         // 7*2*3=42
useCalc(calc,"1/0=");           // 1/0=ERR
useCalc(calc,"+3=");            // +3=ERR
useCalc(calc,"51=");            // 51
```

خودتان تمرین را امتحان کنید، سپس راه‌حل پیشنهادی را در انتهای این پیوست ببینید.

همان‌طور که روی این تمرین کار می‌کنید، وقت بگذارید مزایا/معایب نمایش ماشین‌حساب به عنوان ماژول در مقابل رویکرد تابع closure از تمرین قبلی را در نظر بگیرید.

امتیاز: چند جمله بنویسید که افکارتان را توضیح دهد.

امتیاز ۲: سعی کنید ماژولتان را به فرمت‌های ماژول دیگر تبدیل کنید، از جمله: UMD، CommonJS و ESM (ES Modules).
