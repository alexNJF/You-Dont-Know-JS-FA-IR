# هنوز جاوااسکریپت را نمی‌شناسید: Scope و Closures - ویرایش دوم
# فصل ۵: چرخهٔ حیات (نه چندان مخفی) متغیرها

اکنون باید درک مناسبی از تودرتویی scopeها، از scope سراسری به سمت پایین—به نام scope chain برنامه—داشته باشید.

اما فقط دانستن scope مبدأ یک متغیر فقط بخشی از داستان است. اگر اعلان متغیر بعد از اولین عبارت یک scope ظاهر شود، ارجاع‌ها به آن شناسه *قبل از* اعلان چگونه رفتار خواهند کرد؟ اگر سعی کنید همان متغیر را دو بار در یک scope اعلان کنید چه اتفاقی می‌افتد؟

طعم خاص lexical scope جاوااسکریپت از نظر چگونگی و زمان به‌وجود آمدن و در دسترس شدن متغیرها برای برنامه غنی از ظرافت است.
