# خروج از Scope

چه از فرمت ماژول کلاسیک (مرورگر یا Node)، فرمت CommonJS (در Node)، یا فرمت ESM (مرورگر یا Node) استفاده کنید، ماژول‌ها یکی از مؤثرترین راه‌ها برای ساختاردهی و سازماندهی قابلیت و داده برنامه هستند.

الگوی ماژول نتیجه سفر ما در این کتاب برای یادگیری نحوه استفاده از قوانین lexical scope برای قرار دادن متغیرها و توابع در مکان‌های مناسب است. POLE موضع تدافعی *خصوصی به طور پیش‌فرض* است که همیشه می‌گیریم، مطمئن می‌شویم از مواجهه بیش از حد اجتناب می‌کنیم و فقط با حداقل سطح API عمومی لازم تعامل می‌کنیم.

و زیر ماژول‌ها، *جادوی* نحوه حفظ حالت همه ماژول‌هایمان closureهایی هستند که از سیستم lexical scope استفاده می‌کنند.

متن اصلی همین است. تبریک برای سفر تا اینجا! همان‌طور که بارها در سراسر گفته‌ام، ایده خوبی است که مکث کنید، تأمل کنید و آنچه بحث کردیم را تمرین کنید.

وقتی راحت و آماده بودید، پیوست‌ها را ببینید که عمیق‌تر به گوشه‌های این موضوعات می‌پردازند و همچنین با تمرین‌های عملی شما را به چالش می‌کشند تا آنچه یاد گرفتید را محکم کنید.
