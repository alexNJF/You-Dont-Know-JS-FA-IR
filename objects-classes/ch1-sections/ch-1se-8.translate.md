# ظرف‌های موقت

استفاده از ظرف برای نگه‌داشتن چند مقدار گاهی فقط مکانیزم حمل موقت است، مثل وقتی می‌خواهید چند مقدار را از طریق یک آرگومان به تابع بفرستید، یا وقتی می‌خواهید تابع چند مقدار برگرداند:

```js
function formatValues({ one, two, three }) {
    // شیء واقعی ارسال‌شده به‌عنوان
    // آرگومان قابل دسترسی نیست، چون
    // آن را به سه متغیر جدا
    // destructure کردیم

    one = one.toUpperCase();
    two = `--${two}--`;
    three = three.substring(0,5);

    // این شیء فقط برای حمل
    // هر سه مقدار در یک
    // عبارت return است
    return { one, two, three };
}

// destructure کردن مقدار برگشتی از
// تابع، چون آن شیء برگشتی فقط ظرف
// موقتی برای حمل چند مقدار به ماست
const { one, two, three } =

    // این آرگومان شیء ظرف موقتی
    // برای چند مقدار ورودی است
    formatValues({
       one: "Kyle",
       two: "Simpson",
       three: "getify"
    });

one;     // "KYLE"
two;     // "--Simpson--"
three;   // "getif"
```

literal شیء ارسال‌شده به `formatValues(..)` بلافاصله parameter destructure می‌شود، پس داخل تابع فقط با سه متغیر جدا (`one`، `two` و `three`) سروکار داریم. literal شیء `return`شده از تابع هم بلافاصله destructure می‌شود، پس دوباره فقط با سه متغیر جدا (`one`، `two` و `three`) سروکار داریم.

این قطعه idiom/الگویی را نشان می‌دهد که شیء گاهی فقط ظرف حمل موقت است به‌جای مقدار معنادار به‌خودی‌خود.
