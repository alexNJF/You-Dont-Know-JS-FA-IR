# حذف ویژگی‌ها

وقتی ویژگی روی شیء تعریف شد، تنها راه حذف آن operator `delete` است:

```js
anotherObj = {
    counter: 123
};

anotherObj.counter;   // 123

delete anotherObj.counter;

anotherObj.counter;   // undefined
```

برخلاف تصور رایج، operator `delete` جاوااسکریپت **مستقیماً** هیچ deallocation/آزادسازی حافظه‌ای از طریق garbage collection (GC) انجام نمی‌دهد. تنها کاری که می‌کند حذف ویژگی از شیء است. اگر مقدار در ویژگی ارجاع (به شیء/غیرهٔ دیگر) بود و پس از حذف ویژگی هیچ ارجاع زندهٔ دیگری به آن مقدار نباشد، آن مقدار احتمالاً واجد حذف در sweep آیندهٔ GC می‌شود.

فراخوانی `delete` روی چیزی غیر از ویژگی شیء سوءاستفاده از operator `delete` است و یا ساکت شکست می‌خورد (در حالت non-strict) یا exception پرتاب می‌کند (در حالت strict).

حذف ویژگی از شیء متمایز از انتساب مقداری مثل `undefined` یا `null` به آن است. ویژگی‌ای که `undefined` انتساب شده، چه در ابتدا چه بعداً، هنوز روی شیء حاضر است و ممکن است هنگام شمارش محتویات همچنان آشکار شود.
