# اشیاء به‌عنوان ظرف

یکی از راه‌های رایج گردآوری چند مقدار در یک ظرف واحد استفاده از شیء است. اشیاء مجموعه‌ای از جفت‌های کلید/مقدار هستند. زیرنوع‌های شیء در جاوااسکریپت با رفتارهای تخصصی هم وجود دارند، مثل آرایه‌ها (ایندکس‌شدهٔ عددی) و حتی توابع (قابل فراخوانی)؛ بیشتر دربارهٔ این زیرنوع‌ها بعداً.

| NOTE: |
| :--- |
| کلیدها اغلب «نام ویژگی» نامیده می‌شوند، و جفت شدن نام ویژگی با مقدار اغلب «ویژگی» نامیده می‌شود. این کتاب این اصطلاحات را به‌طور متمایز به این شکل استفاده می‌کند. |

اشیاء معمولی جاوااسکریپت معمولاً با نحو literal اعلان می‌شوند، مثل این:

```js
myObj = {
    // ..
};
```

**توجه:** راه دیگری برای ایجاد شیء وجود دارد (با `myObj = new Object()`)، اما رایج یا ترجیحی نیست و تقریباً هرگز راه مناسب نیست. به نحو literal شیء پایبند باشید.

راحت است گیج شوید که جفت‌های `{ .. }` چه معنایی دارند، چون جاوااسکریپت آکولادها را overload می‌کند تا بسته به زمینهٔ استفاده هر یک از موارد زیر را معنی دهد:

* محدود کردن مقادیر، مثل literalهای شیء
* تعریف الگوهای destructuring شیء (بیشتر بعداً)
* محدود کردن عبارت‌های رشتهٔ درونه‌گذاری‌شده، مثل `` `some ${ getNumber() } thing` ``
* تعریف بلوک‌ها، مثل در حلقه‌های `if` و `for`
* تعریف بدنهٔ توابع

هرچند گاهی هنگام خواندن کد چالش‌برانگیز است، ببینید آیا جفت آکولاد `{ .. }` در جایی از برنامه استفاده شده که مقدار/عبارت معتبر است؛ اگر چنین است، literal شیء است، وگرنه یکی از کاربردهای overloaded دیگر است.
