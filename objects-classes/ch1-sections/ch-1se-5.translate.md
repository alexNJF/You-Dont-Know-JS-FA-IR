# انتساب ویژگی‌ها

چه ویژگی در زمان تعریف literal شیء تعریف شده باشد چه بعداً اضافه شده، انتساب مقدار ویژگی با operator `=` انجام می‌شود، مثل هر انتساب معمولی دیگر:

```js
myObj.favoriteNumber = 123;
```

اگر ویژگی `favoriteNumber` از قبل وجود نداشته باشد، آن عبارت ویژگی جدیدی با آن نام ایجاد و مقدارش را انتساب می‌دهد. اما اگر از قبل وجود داشته باشد، آن عبارت مقدارش را دوباره انتساب می‌دهد.

| WARNING: |
| :--- |
| انتساب `=` به ویژگی ممکن است شکست بخورد (ساکت یا با پرتاب exception)، یا ممکن است مستقیماً مقدار را انتساب نکند بلکه تابع *setter* را فراخوانی کند که عملیاتی انجام می‌دهد. جزئیات بیشتر دربارهٔ این رفتارها در فصل بعد. |

همچنین امکان انتساب یک یا چند ویژگی یکجا وجود دارد — با فرض اینکه ویژگی‌های مبدأ (جفت‌های نام و مقدار) در شیء دیگری هستند — با متد `Object.assign(..)` (اضافه‌شده در ES6):

```js
// کپی shallow همهٔ ویژگی‌های (owned و enumerable)
// از `myObj` به `anotherObj`
Object.assign(anotherObj,myObj);

Object.assign(
    /*target=*/anotherObj,
    /*source1=*/{
        someProp: "some value",
        anotherProp: 1001,
    },
    /*source2=*/{
        yetAnotherProp: false
    }
);
```

`Object.assign(..)` شیء اول را به‌عنوان هدف و شیء دوم (و اختیاری بعدی) را به‌عنوان مبدأ می‌گیرد. کپی به همان شکلی که قبلاً در بخش «Object Spread» توضیح داده شد انجام می‌شود.
