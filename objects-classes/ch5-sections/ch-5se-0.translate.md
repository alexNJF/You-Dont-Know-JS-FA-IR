# هنوز جاوااسکریپت را نمی‌شناسید: اشیاء و کلاس‌ها - ویرایش دوم
# فصل ۵: Delegation

| NOTE: |
| :--- |
| در حال انجام کار |

اشیاء، prototypeها، کلاس‌ها و اکنون کلمهٔ کلیدی `this` را به‌طور کامل کاوش کرده‌ایم. اما اکنون آنچه تا الان یاد گرفته‌ایم را از دیدگاهی کمی متفاوت دوباره می‌بینیم.

اگر می‌توانستید همهٔ قدرت اشیاء، prototypeها و مکانیزم‌های `this` پویا را با هم به کار ببرید، بدون اینکه هرگز از `class` یا هیچ فرزندی از آن استفاده کنید؟

در واقع، استدلال می‌کنم JS ذاتاً کمتر جهت‌یافته به کلاس است از آنچه کلمهٔ کلیدی `class` ممکن است نشان دهد. چون JS زبان پویا و پروتوتایپی است، نقطهٔ قوتش در واقع... *delegation* است.
