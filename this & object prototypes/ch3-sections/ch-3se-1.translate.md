# نحو

Objectها به دو شکل می‌آیند: شکل اعلانی (literal) و شکل ساخته‌شده.

نحو literal برای یک object این‌طور است:

```js
var myObj = {
	key: value
	// ...
};
```

شکل ساخته‌شده این‌طور است:

```js
var myObj = new Object();
myObj.key = value;
```

شکل ساخته‌شده و شکل literal به دقیقاً همان نوع object منجر می‌شوند. تنها تفاوت واقعی این است که می‌توانید یک یا چند جفت key/value به اعلان literal اضافه کنید، در حالی که با objectهای شکل ساخته‌شده باید propertyها را یکی‌یکی اضافه کنید.

**یادداشت:** استفاده از «شکل ساخته‌شده» برای ساختن objectها همان‌طور که نشان داده شد به‌شدت غیرمعمول است. تقریباً همیشه می‌خواهید از شکل نحو literal استفاده کنید. همین برای بیشتر objectهای داخلی هم صادق است (پایین را ببینید).
