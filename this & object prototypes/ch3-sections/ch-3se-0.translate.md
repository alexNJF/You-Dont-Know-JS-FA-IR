# شما جاوااسکریپت را نمی‌دانید: this و Object Prototypes - ویرایش اول
# اشیاء

در فصل‌های ۱ و ۲ توضیح دادیم که binding مربوط به `this` بسته به call-site فراخوانی تابع به objectهای مختلف اشاره می‌کند. اما objectها دقیقاً چه هستند، و چرا باید به آن‌ها اشاره کنیم؟ در این فصل objectها را به‌تفصیل بررسی می‌کنیم.
