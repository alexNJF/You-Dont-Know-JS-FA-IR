# خلاصه (TL;DR)

Objectها در JS هم شکل literal دارند (مثل `var a = { .. }`) و هم شکل ساخته‌شده (مثل `var a = new Array(..)`). شکل literal تقریباً همیشه ترجیح داده می‌شود، اما شکل ساخته‌شده در بعضی موارد گزینه‌های ساخت بیشتری ارائه می‌دهد.

بسیاری به‌اشتباه ادعا می‌کنند «همه‌چیز در جاوااسکریپت یک object است»، اما این نادرست است. Objectها یکی از ۶ (یا ۷، بسته به دیدگاه شما) نوع اولیه‌اند. Objectها زیرنوع دارند، از جمله `function`، و همچنین می‌توانند از نظر رفتار تخصصی باشند، مثل `[object Array]` به‌عنوان برچسب داخلی نمایندهٔ زیرنوع object آرایه.

Objectها مجموعه‌ای از جفت‌های key/value هستند. مقادیر می‌توانند به‌عنوان property با نحو `.propName` یا `["propName"]` دسترسی شوند. هر بار به property دسترسی می‌شود، engine در واقع عملیات داخلی پیش‌فرض `[[Get]]` (و `[[Put]]` برای set کردن مقادیر) را فراخوانی می‌کند، که نه فقط مستقیماً روی object به دنبال property می‌گردد، بلکه در صورت پیدا نکردن زنجیرهٔ `[[Prototype]]` را پیمایش می‌کند (فصل ۵ را ببینید).

Propertyها ویژگی‌های خاصی دارند که می‌توان از طریق property descriptorها کنترل کرد، مثل `writable` و `configurable`. علاوه بر این، objectها می‌توانند تغییرپذیری (و آنِ propertyهایشان) با سطوح مختلف تغییرناپذیری با `Object.preventExtensions(..)`، `Object.seal(..)` و `Object.freeze(..)` کنترل شوند.

Propertyها لازم نیست حتماً مقادیر داشته باشند — می‌توانند «accessor property» هم باشند، با getter/setter. همچنین می‌توانند *enumerable* باشند یا نه، که کنترل می‌کند آیا مثلاً در تکرارهای حلقهٔ `for..in` ظاهر شوند.

همچنین می‌توانید روی **مقادیر** در ساختارهای داده (آرایه‌ها، objectها و غیره) با نحو `for..of` ES6 تکرار کنید، که به دنبال `@@iterator` object داخلی یا سفارشی متشکل از متد `next()` برای پیشروی در مقادیر داده یکی‌یکی می‌گردد.
