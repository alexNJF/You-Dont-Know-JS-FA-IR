# شما جاوااسکریپت را نمی‌دانید: this و Object Prototypes - ویرایش اول
# Prototypeها

در فصل‌های ۳ و ۴ چند بار به زنجیرهٔ `[[Prototype]]` اشاره کردیم، اما نگفتیم دقیقاً چیست. اکنون prototypeها را به‌تفصیل بررسی می‌کنیم.

**یادداشت:** همهٔ تلاش‌ها برای شبیه‌سازی رفتار کپی class، همان‌طور که قبلاً در فصل ۴ توصیف شد و به‌عنوان گونه‌های «mixins» برچسب خورد، کاملاً مکانیزم زنجیرهٔ `[[Prototype]]` که اینجا در این فصل بررسی می‌کنیم را دور می‌زنند.
