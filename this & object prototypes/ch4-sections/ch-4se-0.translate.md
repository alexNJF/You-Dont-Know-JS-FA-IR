# شما جاوااسکریپت را نمی‌دانید: this و Object Prototypes - ویرایش اول
# مخلوط (و اشتباه) اشیاء «کلاس»

در ادامهٔ کاوش objectها از فصل قبل، طبیعی است اکنون به «برنامه‌نویسی شیءگرا (OO)» با «class»ها بپردازیم. اول «class orientation» را به‌عنوان الگوی طراحی می‌بینیم، قبل از بررسی مکانیک «class»ها: «instantiation»، «inheritance» و «(relative) polymorphism».

خواهیم دید که این مفاهیم واقعاً به‌طور طبیعی به مکانیزم object در JS نگاشت نمی‌شوند، و تلاش‌های (mixinها و غیره) بسیاری از توسعه‌دهندگان جاوااسکریپت برای غلبه بر چنین چالش‌هایی.

**یادداشت:** این فصل وقت قابل توجهی (نیمهٔ اول!) روی نظریهٔ سنگین «برنامه‌نویسی شیءگرا» می‌گذارد. در نهایت این ایده‌ها را به کد واقعی جاوااسکریپت در نیمهٔ دوم مربوط می‌کنیم، وقتی از «Mixins» حرف می‌زنیم. اما اول مفاهیم و شبه‌کد زیادی هست، پس گم نشوید — ادامه دهید!
