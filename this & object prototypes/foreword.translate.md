# شما جاوااسکریپت را نمی‌دانید: this و Object Prototypes
# پیش‌گفتار

وقتی این کتاب را برای نوشتن این پیش‌گفتار می‌خواندم، مجبور شدم به این فکر کنم که چطور JavaScript یاد گرفتم و چقدر در ۱۵ سالی که با آن برنامه‌نویسی و توسعه داده‌ام تغییر کرده است.

وقتی ۱۵ سال پیش استفاده از JavaScript را شروع کردم، استفاده از فناوری‌های غیر-HTML مثل CSS و JS در صفحات وب DHTML یا Dynamic HTML نامیده می‌شد. آن زمان، کاربرد JavaScript بسیار متفاوت بود و به نظر می‌رسید بیشتر به سمت اضافه کردن دانه‌های برف متحرک به صفحات وب یا ساعت‌های پویایی که زمان را در نوار وضعیت نشان می‌دادند متمایل است. کافی است بگویم در اوایل کارم واقعاً به JavaScript توجه زیادی نکردم به‌خاطر نوآوری پیاده‌سازی‌هایی که اغلب در اینترنت پیدا می‌کردم.

تا سال ۲۰۰۵ نبود که برای اولین بار JavaScript را به‌عنوان یک زبان برنامه‌نویسی واقعی که باید بیشتر به آن توجه کنم دوباره کشف کردم. بعد از کندوکاو در اولین نسخهٔ بتای Google Maps، به پتانسیل آن معتاد شدم. آن زمان، Google Maps برنامه‌ای بی‌نظیر بود — به شما اجازه می‌داد با ماوس نقشه را جابه‌جا کنید، زوم کنید، و درخواست سرور بدهید بدون بارگذاری مجدد صفحه — همه با JavaScript. مثل جادو به نظر می‌رسید!

وقتی چیزی مثل جادو به نظر می‌رسد، معمولاً نشانهٔ خوبی است که در آستانهٔ روش جدیدی برای انجام کارها هستید. و وای که اشتباه نکردم — با جلو رفتن تا امروز، می‌گویم JavaScript یکی از زبان‌های اصلی‌ای است که برای برنامه‌نویسی سمت کلاینت و سرور استفاده می‌کنم، و هیچ‌طور دیگری را نمی‌خواهم.

یکی از حسرت‌هایم وقتی به ۱۵ سال گذشته نگاه می‌کنم این است که قبل از ۲۰۰۵ به JavaScript فرصت بیشتری ندادم، یا دقیق‌تر بگویم، که بینش دیدن JavaScript به‌عنوان یک زبان برنامه‌نویسی واقعی که به اندازهٔ C++، C#، Java و بسیاری دیگر مفید است را نداشتم.

اگر این مجموعهٔ کتاب *شما جاوااسکریپت را نمی‌دانید* را در ابتدای کارم داشتم، تاریخچهٔ کارم خیلی متفاوت از امروز بود. و این یکی از چیزهایی است که در این مجموعه دوست دارم: JS را در سطحی توضیح می‌دهد که درک شما را هنگام گذر از مجموعه می‌سازد، اما به‌شیوه‌ای سرگرم‌کننده و آموزنده.

*this و Object Prototypes* ادامهٔ فوق‌العادهٔ مجموعه است. کار عالی و طبیعیِ ساختن بر پایهٔ کتاب قبلی، Scope و Closures، و گسترش آن دانش به بخش بسیار مهمی از زبان JS — کلمهٔ کلیدی `this` و prototypeها — را انجام می‌دهد. این دو چیز ساده برای آنچه در کتاب‌های بعدی یاد خواهید گرفت محوری‌اند، چون بنیاد برنامه‌نویسی واقعی با JavaScript هستند. مفهوم چگونگی ایجاد اشیاء، ارتباط دادن آن‌ها، و گسترش آن‌ها برای نمایش چیزها در برنامه‌تان برای ایجاد برنامه‌های بزرگ و پیچیده در JavaScript ضروری است. و بدون آن‌ها، ایجاد برنامه‌های پیچیده (مثل Google Maps) در JavaScript ممکن نبود.

می‌گویم اکثر توسعه‌دهندگان وب احتمالاً هرگز یک object جاوااسکریپت نساخته‌اند و فقط زبان را به‌عنوان چسب event-binding بین دکمه‌ها و درخواست‌های AJAX تلقی می‌کنند. من در مقطعی از کارم در آن اردوگاه بودم، اما بعد از یادگیری تسلط بر prototypeها و ایجاد اشیاء در JavaScript، دنیایی از امکانات برایم گشوده شد. اگر در دستهٔ کسانی هستید که فقط کد چسب event-binding می‌نویسند، این کتاب باید خوانده شود؛ اگر فقط به یادآوری نیاز دارید، این کتاب منبعی در دسترس برایتان خواهد بود. در هر صورت، ناامید نخواهید شد. به من اعتماد کنید!
