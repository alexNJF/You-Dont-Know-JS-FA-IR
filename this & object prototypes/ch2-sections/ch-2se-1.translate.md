# Call-site

برای فهم binding مربوط به `this`، باید call-site را بفهمیم: محل در کد که تابع فراخوانی می‌شود (**نه جایی که تعریف شده**). باید call-site را بررسی کنیم تا به این سؤال پاسخ دهیم: این `this` به چه چیزی اشاره می‌کند؟

پیدا کردن call-site عموماً این است: «برو ببین تابع از کجا فراخوانی شده»، اما همیشه آن‌قدر آسان نیست، چون الگوهای کدنویسی خاص می‌توانند *واقعی* call-site را پنهان کنند.

مهم این است که به **call-stack** (پشتهٔ توابعی که برای رسیدن به لحظهٔ فعلی اجرا فراخوانی شده‌اند) فکر کنیم. call-siteی که برایمان مهم است *داخل* فراخوانی *قبل از* تابع در حال اجراست.

بیایید call-stack و call-site را نشان دهیم:

```js
function baz() {
    // call-stack is: `baz`
    // so, our call-site is in the global scope

    console.log( "baz" );
    bar(); // <-- call-site for `bar`
}

function bar() {
    // call-stack is: `baz` -> `bar`
    // so, our call-site is in `baz`

    console.log( "bar" );
    foo(); // <-- call-site for `foo`
}

function foo() {
    // call-stack is: `baz` -> `bar` -> `foo`
    // so, our call-site is in `bar`

    console.log( "foo" );
}

baz(); // <-- call-site for `baz`
```

در تحلیل کد برای پیدا کردن call-site واقعی (از call-stack) دقت کنید، چون تنها چیزی است که برای binding مربوط به `this` اهمیت دارد.

**یادداشت:** می‌توانید call-stack را در ذهن با نگاه به زنجیرهٔ فراخوانی‌های تابع به ترتیب تصور کنید، همان‌طور که با توضیحات در قطعهٔ بالا کردیم. اما این پرزحمت و مستعد خطاست. راه دیگر دیدن call-stack استفاده از ابزار debugger در مرورگر است. بیشتر مرورگرهای دسکتاپ مدرن ابزارهای توسعه‌دهندهٔ داخلی دارند که شامل یک JS debugger است. در قطعهٔ بالا می‌توانستید در ابزارها یک breakpoint برای خط اول تابع `foo()` بگذارید، یا به‌سادگی دستور `debugger;` را در آن خط اول درج کنید. وقتی صفحه را اجرا کنید، debugger در این محل متوقف می‌شود و فهرستی از توابعی که برای رسیدن به آن خط فراخوانی شده‌اند را نشان می‌دهد که call stack شماست. پس اگر می‌خواهید binding مربوط به `this` را تشخیص دهید، از ابزارهای توسعه‌دهنده برای گرفتن call-stack استفاده کنید، سپس مورد دوم از بالا را پیدا کنید، و آن call-site واقعی را نشان می‌دهد.
