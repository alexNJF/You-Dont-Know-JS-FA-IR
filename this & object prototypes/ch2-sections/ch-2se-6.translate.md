# خلاصه (TL;DR)

تعیین binding مربوط به `this` برای تابع در حال اجرا نیاز به پیدا کردن call-site مستقیم آن تابع دارد. وقتی بررسی شد، چهار قانون را می‌توان به call-site اعمال کرد، به *این* ترتیب اولویت:

1. با `new` فراخوانی شده؟ از object تازه ساخته‌شده استفاده کنید.

2. با `call` یا `apply` (یا `bind`) فراخوانی شده؟ از object مشخص‌شده استفاده کنید.

3. با context object مالک فراخوانی فراخوانی شده؟ از آن context object استفاده کنید.

4. پیش‌فرض: `undefined` در `strict mode`، وگرنه global object.

از فراخوانی تصادفی/ناخواستهٔ قانون *default binding* مراقب باشید. در مواردی که می‌خواهید binding مربوط به `this` را «امن» نادیده بگیرید، یک object «DMZ» مثل `ø = Object.create(null)` مقدار placeholder خوبی است که global object را از اثرات جانبی ناخواسته محافظت می‌کند.

به‌جای چهار قانون استاندارد binding، arrow-functionهای ES6 از lexical scoping برای binding مربوط به `this` استفاده می‌کنند، یعنی binding مربوط به `this` (هرچه باشد) را از فراخوانی تابع احاطه‌کننده می‌گیرند. در اصل جایگزین نحوی `self = this` در کدنویسی قبل از ES6 هستند.
